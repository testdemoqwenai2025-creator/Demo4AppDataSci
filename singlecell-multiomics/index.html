10x GEM + UMI math — Poisson barcoding with error correction
mathematics
10x Genomics loads cells at Poisson(λ=0.1) per droplet — 90% empty (wasted), 9% single-cell (useful), 1% doublets (filtered). UMIs (10-12bp random sequences) are appended to each cDNA before PCR, allowing deduplication of PCR duplicates. UMI collision (two originals sharing same UMI) is ~10⁻⁵ per (cell, gene) — negligible.

P(k cells/droplet) = e-λ·λk/k!  ·  P(doublet) ≈ λ²/2

λ=0.1 cells/droplet. P(doublet) = 0.005 (0.5%). UMI length 10bp × 4 bases = 4¹⁰ ≈ 10⁶ codes per (cell, gene).

count = |distinct UMIs|

scVI math — ZINB likelihood for zero-inflated count data
mathematics
scRNA-seq counts have two features: (1) zero-inflation (90%+ of (cell, gene) pairs are zero — most genes are not expressed in most cells), (2) over-dispersion (variance > mean, captured by negative binomial). scVI's ZINB likelihood = π·δ(x=0) + (1-π)·NB(x|μ,θ) handles both. The VAE encoder compresses 20K-dim counts → 30-dim latent (cell-type identity, batch-corrected via conditional encoder).

P(x | μ, θ, π) = π · δ(x=0) + (1-π) · NB(x | μ, θ)  ·  KL(q(z|x,batch) || N(0, I))

π = dropout probability (per-cell, per-gene), μ = mean (positive), θ = dispersion (per-gene). VAE encoder compresses counts → 30-dim latent.

Negative Binomial

NB(x|μ,θ) = Γ(x+θ)/(Γ(θ)·x!) · (θ/(θ+μ))θ · (μ/(θ+μ))x

Models over-dispersion: Var = μ + μ²/θ. θ→∞: Poisson. θ small: highly over-dispersed.

Zero-inflation π

π = sigmoid(W·z + b)

Per-cell, per-gene dropout. If π high: dropout dominates (technical zero). If π low: true biological zero.

KL regularisation

KL = -0.5 · Σ (1 + logvar - μ² - elogvar)

Pulls latent posterior q(z|x) toward N(0, I) prior. Prevents overfitting; allows sampling for downstream.

RNA velocity math — kinetic ODE for cell-state transitions
mathematics
La Manno 2018 measured unspliced (intronic) vs spliced (exonic) mRNA per cell. The ratio reveals whether a gene is being transcribed (high u/s) or degraded (low u/s). Solving the kinetic ODE du/dt = α - β·u, ds/dt = β·u - γ·s gives per-cell velocity v = ds/dt = β·u - γ·s — the rate of cell-state transition. Projecting velocities onto UMAP reveals differentiation arrows.

du/dt = α - β·u  ·  ds/dt = β·u - γ·s  ·  v = β·u - γ·s

α = transcription rate, β = splicing rate, γ = degradation rate. Steady state: u* = α/β, s* = α/γ → estimate γ via linear regression of u vs s.

Steady state

u* = (γ/β)·s*

Linear regression of u vs s across cells. Slope ≈ γ/β. Bergens 2020 scVelo improves via EM (relaxation of constant-rate assumption).

Velocity sign

v > 0: up-regulating (active transcription)

v < 0: down-regulating (degradation dominates). v = 0: at steady state (mature cell).

Projection to embedding

arrow_i = Σ w_ij · (e_j - e_i)

For each cell, weight k-NN displacements by cosine sim of gene-space velocity. Sum gives embedding-space arrow.

Modern papers — scVI, WNN/Seurat v4, RNA velocity, Harmony
The four reference methods for single-cell multi-omics: (1) scVI (Lopez 2018, Nature Methods) — VAE with ZINB likelihood. (2) Seurat v4 + WNN (Hao 2021, Cell) — weighted KNN integration. (3) RNA velocity (La Manno 2018, Bergen 2020) — kinetic ODE. (4) Harmony (Korsunsky 2019, Nature Methods) — fast batch correction.

scVI (Lopez et al. 2018, Nature Methods): Variational autoencoder for scRNA-seq with zero-inflated negative binomial likelihood. Encoder: counts + batch → 30-dim latent. Decoder: latent + batch → (μ, θ, π) for ZINB. Handles zero-inflation (90%+ zeros in count matrix) and over-dispersion (variance > mean). Production: scVI-tools ecosystem (scANVI for semi-supervised, totalVI for CITE-seq). Replaces PCA + Harmony for batch-corrected embeddings.

Seurat v4 + WNN (Hao et al. 2021, Cell): Weighted Nearest Neighbours integration for paired multi-modal data (10x Multiome: RNA + ATAC on same cell). For each cell: find k-NN in each modality, compute per-cell modality weights via softmax of k-NN quality, rank combined neighbours by weighted similarity. Output: cell × cell WNN graph for clustering. Outperforms simple concatenation (RNA + ATAC) by 30%+ on cell-type identification. The reference for 10x Multiome analysis.

RNA velocity (La Manno et al. 2018, Nature; Bergen et al. 2020 scVelo, Nature Biotechnology): Measures unspliced (intronic) vs spliced (exonic) mRNA per cell. The ratio u/s reveals transcription direction. Solves the kinetic ODE du/dt = α - β·u, ds/dt = β·u - γ·s to estimate per-cell velocity v = β·u - γ·s. scVelo (2020) extends via EM for kinetic parameter estimation (relaxes the constant-rate assumption). Reveals differentiation trajectories invisible to static embeddings.

Harmony (Korsunsky et al. 2019, Nature Methods): Fast iterative batch correction. Algorithm: PCA on combined data, initialise k cluster centres, soft cluster assignment per cell, subtract batch-specific means, re-assign clusters. Converges in <10 iterations, ~1000× faster than scVI VAE training. When batch effects are simple (technical, not biological), Harmony is preferred. When batch effects are complex (multi-site, mixed protocols), scVI's VAE handles better. Production: try Harmony first, fall back to scVI if needed.

11class ZINBLoss(nn.Module):
12    """Zero-Inflated Negative Binomial loss.
13    
14    P(x | μ, θ, π) = π · δ(x=0) + (1-π) · NB(x | μ, θ)
15    
16    where NB(x | μ, θ) = Γ(x+θ) / (Γ(θ) · x!) · (θ/(θ+μ))^θ · (μ/(θ+μ))^x
17    
18    Production: scVI library (Lopez 2018).
19    """
20    def __init__(self):
21        super().__init__()
22    
23    def forward(self, x: torch.Tensor, mu: torch.Tensor,
24                theta: torch.Tensor, pi: torch.Tensor) -> torch.Tensor:
25        """Compute ZINB negative log-likelihood.
26        
27        Args:
28            x: (B, G) observed counts
29            mu: (B, G) mean (positive, exp of decoder output)
30            theta: (G,) dispersion (positive)
31            pi: (B, G) dropout probability (0-1)
32        """
33        eps = 1e-8
34        # Negative binomial log-likelihood
35        log_theta_mu = torch.log(theta + mu + eps)
36        # Γ terms approximated via lgamma
37        log_nb = (
38            torch.lgamma(x + theta) - torch.lgamma(theta) - torch.lgamma(x + 1)
39            + theta * (torch.log(theta + eps) - log_theta_mu)
40            + x * (torch.log(mu + eps) - log_theta_mu)
41        )
42        # Zero-inflation mixture
43        log_pi_zero = torch.log(pi + eps)  # log P(x=0 | dropout)
44        log_one_minus_pi = torch.log(1 - pi + eps)
45        # Mixture: P(x | ...) = π · δ(x=0) + (1-π) · NB
46        log_prob = torch.where(
47            x == 0,
48            torch.logsumexp(torch.stack([log_pi_zero, log_one_minus_pi + log_nb], dim=-1), dim=-1),
49            log_one_minus_pi + log_nb,
50        )
51        return -log_prob.sum(dim=-1).mean()

54    """scVI (Lopez 2018) — Variational Autoencoder for scRNA-seq.
55    
56    Architecture:
57        Encoder: counts (B, G) + batch (B, B_dim) → (μ_z, σ_z) → latent z (B, latent_dim)
58        Decoder: z + batch → (μ, π) → ZINB likelihood
59    
60    Latent z captures cell-type identity, batch-corrected via conditional encoder.
61    """
62    def __init__(self, n_genes: int = 20000, latent_dim: int = 30,
63                 hidden_dim: int = 256, n_batch: int = 10):
64        super().__init__()
65        self.n_genes = n_genes
66        self.latent_dim = latent_dim
67        
68        # Encoder: (counts, batch_onehot) → (μ_z, log_var_z)
69        encoder_input_dim = n_genes + n_batch
70        self.encoder = nn.Sequential(
71            nn.Linear(encoder_input_dim, hidden_dim),
72            nn.LayerNorm(hidden_dim),
73            nn.ReLU(),
74            nn.Dropout(0.1),
75            nn.Linear(hidden_dim, hidden_dim),
76            nn.LayerNorm(hidden_dim),
77            nn.ReLU(),
78        )
79        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
80        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)
81        
82        # Decoder: (z, batch_onehot) → (μ, log_θ, π)
83        decoder_input_dim = latent_dim + n_batch
84        self.decoder = nn.Sequential(
85            nn.Linear(decoder_input_dim, hidden_dim),
86            nn.LayerNorm(hidden_dim),
87            nn.ReLU(),
88            nn.Dropout(0.1),
89            nn.Linear(hidden_dim, n_genes),
90        )
91        # Per-gene dispersion (learnable)
92        self.theta = nn.Parameter(torch.randn(n_genes))
93        # Dropout (per-cell, per-gene)
94        self.dropout = nn.Linear(decoder_input_dim, n_genes)
95    
96    def encode(self, x: torch.Tensor, batch: torch.Tensor) -> Tuple[torch.Tensor, torch.Tensor]:
97        """Encode (counts, batch) → (μ, log_var)."""
98        h = torch.cat([x, batch], dim=-1)
99        h = self.encoder(h)
100        return self.fc_mu(h), self.fc_logvar(h)
101    
102    def reparameterize(self, mu: torch.Tensor, logvar: torch.Tensor) -> torch.Tensor:
103        """Reparameterisation trick: z = mu + std * eps."""
104        std = torch.exp(0.5 * logvar)
105        eps = torch.randn_like(std)
106        return mu + eps * std
107    
108    def decode(self, z: torch.Tensor, batch: torch.Tensor) -> Dict[str, torch.Tensor]:
109        """Decode (z, batch) → (μ, θ, π) for ZINB likelihood."""
110        h = torch.cat([z, batch], dim=-1)
111        # Mean (positive)
112        mu = torch.exp(self.decoder(h))  # (B, G)
113        # Dispersion (per-gene, positive)
114        theta = torch.exp(self.theta)  # (G,)
115        # Dropout (per-cell, per-gene)
116        pi = torch.sigmoid(self.dropout(h))  # (B, G)
117        return {'mu': mu, 'theta': theta, 'pi': pi}
118    
119    def forward(self, x: torch.Tensor, batch: torch.Tensor) -> Dict[str, torch.Tensor]:
120        """Forward pass.
121        
122        Args:
123            x: (B, G) gene count matrix (sparse-encoded as dense for simplicity)
124            batch: (B, n_batch) one-hot batch IDs
125        
126        Returns: dict with 'latent', 'mu', 'theta', 'pi', 'kl'
127        """
128        mu_z, logvar_z = self.encode(x, batch)
129        z = self.reparameterize(mu_z, logvar_z)
130        out = self.decode(z, batch)
131        out['latent'] = z
132        out['mu_z'] = mu_z
133        out['logvar_z'] = logvar_z
134        # KL divergence: 0.5 * Σ (1 + logvar - mu² - exp(logvar))
135        out['kl'] = -0.5 * torch.sum(1 + logvar_z - mu_z.pow(2) - logvar_z.exp(), dim=-1)
136        return out
137    
138    def loss(self, x: torch.Tensor, batch: torch.Tensor) -> torch.Tensor:
139        """scVI loss: ZINB reconstruction + KL."""
140        out = self.forward(x, batch)
141        # Reconstruction (ZINB)
142        zinb = ZINBLoss()
143        recon_loss = zinb(x, out['mu'], out['theta'], out['pi'])
144        # KL
145        kl_loss = out['kl'].mean()
146        return recon_loss + 1e-4 * kl_loss

152class WNN(nn.Module):
153    """WNN (Hao 2021, Seurat v4) — Weighted Nearest Neighbours integration.
154    
155    For paired multi-modal data (e.g. 10x Multiome: RNA + ATAC on same cell):
156        1. Embed RNA via scVI (this class wraps)
157        2. Embed ATAC via LSI (TF-IDF + SVD)
158        3. For each cell: find k-NN in each modality
159        4. Compute per-cell modality weights (softmax over k-NN quality)
160        5. Combined k-NN graph: rank by w_RNA · sim_RNA + w_ATAC · sim_ATAC
161    
162    Output: cell × cell WNN graph for clustering / UMAP.
163    """
164    def __init__(self, rna_dim: int, atac_dim: int, k: int = 30):
165        super().__init__()
166        self.k = k
167        # Modality embeddings (pre-computed by scVI / LSI)
168        # Here: learned projectors for demo
169        self.rna_proj = nn.Linear(rna_dim, 30)
170        self.atac_proj = nn.Linear(atac_dim, 30)
171        # Per-cell modality weights (softmax over 2 modalities)
172        self.weight_scorer = nn.Sequential(
173            nn.Linear(30 * 2, 16),
174            nn.ReLU(),
175            nn.Linear(16, 2),  # (w_RNA, w_ATAC)
176        )
177    
178    def forward(self, rna_emb: torch.Tensor, atac_emb: torch.Tensor) -> Dict[str, torch.Tensor]:
179        """Compute WNN graph.
180        
181        Args:
182            rna_emb: (N, rna_dim) RNA embeddings
183            atac_emb: (N, atac_dim) ATAC embeddings
184        
185        Returns: dict with 'wnn_graph' (N, N), 'modality_weights' (N, 2)
186        """
187        # Project to common space
188        rna_proj = self.rna_proj(rna_emb)  # (N, 30)
189        atac_proj = self.atac_proj(atac_emb)  # (N, 30)
190        
191        # Normalise for cosine similarity
192        rna_proj = F.normalize(rna_proj, dim=-1)
193        atac_proj = F.normalize(atac_proj, dim=-1)
194        
195        # Per-cell modality weights
196        combined = torch.cat([rna_proj, atac_proj], dim=-1)  # (N, 60)
197        modality_weights = F.softmax(self.weight_scorer(combined), dim=-1)  # (N, 2)
198        
199        # Compute similarities (N, N)
200        sim_rna = rna_proj @ rna_proj.T  # cosine similarity
201        sim_atac = atac_proj @ atac_proj.T
202        
203        # WNN: weighted combination per cell
204        # w_cell = (w_RNA, w_ATAC) per cell — broadcast to (N, 1, 2)
205        w = modality_weights.unsqueeze(1)  # (N, 1, 2)
206        # sim: (N, N, 2) where dim=-1 is (RNA, ATAC)
207        sim_stack = torch.stack([sim_rna, sim_atac], dim=-1)  # (N, N, 2)
208        wnn = (w * sim_stack).sum(dim=-1)  # (N, N)
209        
210        return {'wnn_graph': wnn, 'modality_weights': modality_weights}

216class RNAVelocitySolver:
217    """RNA velocity (La Manno 2018, Bergen 2020 scVelo).
218    
219    For each gene per cell:
220        u = unspliced mRNA (intronic reads)
221        s = spliced mRNA (exonic reads)
222        
223    Kinetic ODE:
224        du/dt = α - β·u
225        ds/dt = β·u - γ·s
226        
227    Velocity:
228        v = ds/dt = β·u - γ·s  (cell-state transition rate)
229    
230    Production: scVelo (Bergen 2020) uses EM for kinetic parameter estimation.
231    """
232    @staticmethod
233    def estimate_gamma(unspliced: torch.Tensor, spliced: torch.Tensor) -> torch.Tensor:
234        """Estimate γ per gene via linear regression on steady-state cells.
235        
236        At steady state: u = (γ/β) · s
237        → Linear regression: u = slope · s + offset
238        → slope ≈ γ/β (assuming β=1)
239        
240        Args:
241            unspliced: (N_cells, N_genes) intronic counts
242            spliced: (N_cells, N_genes) exonic counts
243        
244        Returns: gamma (N_genes,)
245        """
246        # Per-gene linear regression via least squares
247        # u = γ · s + offset
248        n_cells, n_genes = unspliced.shape
249        
250        # Center: subtract means
251        u_mean = unspliced.mean(dim=0)  # (N_genes,)
252        s_mean = spliced.mean(dim=0)
253        u_centered = unspliced - u_mean
254        s_centered = spliced - s_mean
255        
256        # γ = (s · u) / (s · s) per gene
257        numerator = (s_centered * u_centered).sum(dim=0)  # (N_genes,)
258        denominator = (s_centered ** 2).sum(dim=0) + 1e-8
259        gamma = numerator / denominator  # (N_genes,)
260        return torch.clamp(gamma, min=0.01, max=10.0)
261    
262    @staticmethod
263    def compute_velocity(unspliced: torch.Tensor, spliced: torch.Tensor,
264                         gamma: torch.Tensor = None, beta: float = 1.0) -> torch.Tensor:
265        """Compute per-cell velocity.
266        
267        v = β · u - γ · s  (per gene, per cell)
268        
269        Args:
270            unspliced: (N_cells, N_genes)
271            spliced: (N_cells, N_genes)
272            gamma: (N_genes,) — if None, estimate from data
273            beta: scalar splicing rate
274        
275        Returns: (N_cells, N_genes) velocity per gene per cell
276        """
277        if gamma is None:
278            gamma = RNAVelocitySolver.estimate_gamma(unspliced, spliced)
279        # v = β · u - γ · s
280        v = beta * unspliced - gamma.unsqueeze(0) * spliced
281        return v
282    
283    @staticmethod
284    def project_velocity_to_embedding(velocity: torch.Tensor, embedding: torch.Tensor,
285                                       neighbour_graph: torch.Tensor) -> torch.Tensor:
286        """Project gene-space velocity to embedding space (UMAP / PCA).
287        
288        For each cell, average velocity of k nearest neighbours.
289        
290        Args:
291            velocity: (N_cells, N_genes) per-gene velocity
292            embedding: (N_cells, 2) 2D embedding (UMAP)
293            neighbour_graph: (N_cells, k) indices of k-NN
294        
295        Returns: (N_cells, 2) velocity arrows in embedding space
296        """
297        N, k = neighbour_graph.shape
298        # For each cell, compute transition probability to each neighbour
299        # (based on cosine similarity of velocity vectors)
300        # Then sum: weighted displacement in embedding space
301        arrows = torch.zeros(N, 2)
302        for i in range(N):
303            nbrs = neighbour_graph[i]  # (k,)
304            # Velocity of cell i in gene space
305            v_i = velocity[i]  # (N_genes,)
306            # Cosine sim of v_i with delta_embedding to each neighbour
307            delta_emb = embedding[nbrs] - embedding[i]  # (k, 2)
308            # Project v_i onto delta_emb (simplified: just use cosine sim of velocity)
309            # Production: project via kernel matrix (scVelo uses Gaussian kernel)
310            weights = F.cosine_similarity(v_i.unsqueeze(0).expand(k, -1),
311                                            delta_emb, dim=-1)  # (k,)
312            weights = F.softmax(weights, dim=0)  # normalise
313            # Weighted sum of deltas
314            arrows[i] = (weights.unsqueeze(-1) * delta_emb).sum(dim=0)
315        return arrows

321class Harmony(nn.Module):
322    """Harmony (Korsunsky 2019) — fast batch correction.
323    
324    Algorithm:
325        1. PCA on combined data (all batches)
326        2. Initialise k cluster centres
327        3. For each iteration:
328           a. Soft cluster assignment per cell (responsibilities)
329           b. For each cell: subtract batch-specific mean
330           c. Re-assign clusters
331    
332    Converges in &lt;10 iterations, ~1000× faster than scVI's full VAE training.
333    """
334    def __init__(self, n_clusters: int = 20, max_iter: int = 10):
335        super().__init__()
336        self.n_clusters = n_clusters
337        self.max_iter = max_iter
338        # Cluster centres (learned)
339        self.cluster_centres = nn.Parameter(torch.randn(n_clusters, 30))
340        # Batch correction: per-batch means
341        # (computed at runtime, not stored)
342    
343    def forward(self, embeddings: torch.Tensor, batch_ids: torch.Tensor) -> torch.Tensor:
344        """Harmony batch correction.
345        
346        Args:
347            embeddings: (N, 30) PCA-reduced cell embeddings
348            batch_ids: (N,) integer batch IDs
349        
350        Returns: (N, 30) batch-corrected embeddings
351        """
352        corrected = embeddings.clone()
353        for _ in range(self.max_iter):
354            # Soft cluster assignment: cosine sim to centres
355            sim = F.cosine_similarity(
356                corrected.unsqueeze(1),  # (N, 1, 30)
357                self.cluster_centres.unsqueeze(0),  # (1, K, 30)
358                dim=-1
359            )  # (N, K)
360            responsibilities = F.softmax(sim * 10, dim=-1)  # (N, K) — temperature 10
361            
362            # For each cell, compute batch-specific mean
363            for batch_id in torch.unique(batch_ids):
364                mask = (batch_ids == batch_id)
365                # Weighted mean of cluster centres for this batch
366                weighted_centres = responsibilities[mask] @ self.cluster_centres  # (n_batch_cells, 30)
367                batch_mean = weighted_centres.mean(dim=0)  # (30,)
368                # Subtract batch mean (correction)
369                corrected[mask] = embeddings[mask] - batch_mean + self.cluster_centres.mean(dim=0)
370        
371        return corrected

10x GEM + UMI math — Poisson barcoding with error correction
mathematics
10x Genomics loads cells at Poisson(λ=0.1) per droplet — 90% empty (wasted), 9% single-cell (useful), 1% doublets (filtered). UMIs (10-12bp random sequences) are appended to each cDNA before PCR, allowing deduplication of PCR duplicates. UMI collision (two originals sharing same UMI) is ~10⁻⁵ per (cell, gene) — negligible.

λ=0.1 cells/droplet. P(doublet) = 0.005 (0.5%). UMI length 10bp × 4 bases = 4¹⁰ ≈ 10⁶ codes per (cell, gene).

scVI math — ZINB likelihood for zero-inflated count data
mathematics
scRNA-seq counts have two features: (1) zero-inflation (90%+ of (cell, gene) pairs are zero — most genes are not expressed in most cells), (2) over-dispersion (variance > mean, captured by negative binomial). scVI's ZINB likelihood = π·δ(x=0) + (1-π)·NB(x|μ,θ) handles both. The VAE encoder compresses 20K-dim counts → 30-dim latent (cell-type identity, batch-corrected via conditional encoder).

P(x | μ, θ, π) = π · δ(x=0) + (1-π) · NB(x | μ, θ)  ·  KL(q(z|x,batch) || N(0, I))

π = dropout probability (per-cell, per-gene), μ = mean (positive), θ = dispersion (per-gene). VAE encoder compresses counts → 30-dim latent.

Negative Binomial

NB(x|μ,θ) = Γ(x+θ)/(Γ(θ)·x!) · (θ/(θ+μ))θ · (μ/(θ+μ))x

Models over-dispersion: Var = μ + μ²/θ. θ→∞: Poisson. θ small: highly over-dispersed.

Zero-inflation π

π = sigmoid(W·z + b)

Per-cell, per-gene dropout. If π high: dropout dominates (technical zero). If π low: true biological zero.

KL regularisation

KL = -0.5 · Σ (1 + logvar - μ² - elogvar)

Pulls latent posterior q(z|x) toward N(0, I) prior. Prevents overfitting; allows sampling for downstream.

RNA velocity math — kinetic ODE for cell-state transitions
mathematics
La Manno 2018 measured unspliced (intronic) vs spliced (exonic) mRNA per cell. The ratio reveals whether a gene is being transcribed (high u/s) or degraded (low u/s). Solving the kinetic ODE du/dt = α - β·u, ds/dt = β·u - γ·s gives per-cell velocity v = ds/dt = β·u - γ·s — the rate of cell-state transition. Projecting velocities onto UMAP reveals differentiation arrows.

du/dt = α - β·u  ·  ds/dt = β·u - γ·s  ·  v = β·u - γ·s

α = transcription rate, β = splicing rate, γ = degradation rate. Steady state: u* = α/β, s* = α/γ → estimate γ via linear regression of u vs s.

Steady state

u* = (γ/β)·s*

Linear regression of u vs s across cells. Slope ≈ γ/β. Bergens 2020 scVelo improves via EM (relaxation of constant-rate assumption).

Velocity sign

v > 0: up-regulating (active transcription)

v < 0: down-regulating (degradation dominates). v = 0: at steady state (mature cell).

Projection to embedding

arrow_i = Σ w_ij · (e_j - e_i)

For each cell, weight k-NN displacements by cosine sim of gene-space velocity. Sum gives embedding-space arrow.

Modern papers — scVI, WNN/Seurat v4, RNA velocity, Harmony
The four reference methods for single-cell multi-omics: (1) scVI (Lopez 2018, Nature Methods) — VAE with ZINB likelihood. (2) Seurat v4 + WNN (Hao 2021, Cell) — weighted KNN integration. (3) RNA velocity (La Manno 2018, Bergen 2020) — kinetic ODE. (4) Harmony (Korsunsky 2019, Nature Methods) — fast batch correction.

scVI (Lopez et al. 2018, Nature Methods): Variational autoencoder for scRNA-seq with zero-inflated negative binomial likelihood. Encoder: counts + batch → 30-dim latent. Decoder: latent + batch → (μ, θ, π) for ZINB. Handles zero-inflation (90%+ zeros in count matrix) and over-dispersion (variance > mean). Production: scVI-tools ecosystem (scANVI for semi-supervised, totalVI for CITE-seq). Replaces PCA + Harmony for batch-corrected embeddings.

Seurat v4 + WNN (Hao et al. 2021, Cell): Weighted Nearest Neighbours integration for paired multi-modal data (10x Multiome: RNA + ATAC on same cell). For each cell: find k-NN in each modality, compute per-cell modality weights via softmax of k-NN quality, rank combined neighbours by weighted similarity. Output: cell × cell WNN graph for clustering. Outperforms simple concatenation (RNA + ATAC) by 30%+ on cell-type identification. The reference for 10x Multiome analysis.

RNA velocity (La Manno et al. 2018, Nature; Bergen et al. 2020 scVelo, Nature Biotechnology): Measures unspliced (intronic) vs spliced (exonic) mRNA per cell. The ratio u/s reveals transcription direction. Solves the kinetic ODE du/dt = α - β·u, ds/dt = β·u - γ·s to estimate per-cell velocity v = β·u - γ·s. scVelo (2020) extends via EM for kinetic parameter estimation (relaxes the constant-rate assumption). Reveals differentiation trajectories invisible to static embeddings.

Harmony (Korsunsky et al. 2019, Nature Methods): Fast iterative batch correction. Algorithm: PCA on combined data, initialise k cluster centres, soft cluster assignment per cell, subtract batch-specific means, re-assign clusters. Converges in <10 iterations, ~1000× faster than scVI VAE training. When batch effects are simple (technical, not biological), Harmony is preferred. When batch effects are complex (multi-site, mixed protocols), scVI's VAE handles better. Production: try Harmony first, fall back to scVI if needed.

low-level
The actual production code. scVI implements the full VAE: encoder (counts + batch one-hot → 2-layer MLP → μ, logvar), reparameterise trick, decoder (z + batch → μ via exp, θ per-gene, π via sigmoid), ZINBLoss with lgamma for Γ terms. WNN does paired integration: project RNA + ATAC to common 30-dim, compute per-cell modality weights via softmax of 2-layer MLP, weighted combination of cosine similarities. RNAVelocitySolver estimates γ via least-squares regression of unspliced vs spliced, computes v = β·u - γ·s, projects to embedding via cosine sim of velocities with k-NN displacements. Harmony does iterative batch correction via soft cluster responsibilities + per-batch mean subtraction.

11class ZINBLoss(nn.Module):
12    """Zero-Inflated Negative Binomial loss.
13    
14    P(x | μ, θ, π) = π · δ(x=0) + (1-π) · NB(x | μ, θ)
15    
16    where NB(x | μ, θ) = Γ(x+θ) / (Γ(θ) · x!) · (θ/(θ+μ))^θ · (μ/(θ+μ))^x
17    
18    Production: scVI library (Lopez 2018).
19    """
20    def __init__(self):
21        super().__init__()
22    
23    def forward(self, x: torch.Tensor, mu: torch.Tensor,
24                theta: torch.Tensor, pi: torch.Tensor) -> torch.Tensor:
25        """Compute ZINB negative log-likelihood.
26        
27        Args:
28            x: (B, G) observed counts
29            mu: (B, G) mean (positive, exp of decoder output)
30            theta: (G,) dispersion (positive)
31            pi: (B, G) dropout probability (0-1)
32        """
33        eps = 1e-8
34        # Negative binomial log-likelihood
35        log_theta_mu = torch.log(theta + mu + eps)
36        # Γ terms approximated via lgamma
37        log_nb = (
38            torch.lgamma(x + theta) - torch.lgamma(theta) - torch.lgamma(x + 1)
39            + theta * (torch.log(theta + eps) - log_theta_mu)
40            + x * (torch.log(mu + eps) - log_theta_mu)
41        )
42        # Zero-inflation mixture
43        log_pi_zero = torch.log(pi + eps)  # log P(x=0 | dropout)
44        log_one_minus_pi = torch.log(1 - pi + eps)
45        # Mixture: P(x | ...) = π · δ(x=0) + (1-π) · NB
46        log_prob = torch.where(
47            x == 0,
48            torch.logsumexp(torch.stack([log_pi_zero, log_one_minus_pi + log_nb], dim=-1), dim=-1),
49            log_one_minus_pi + log_nb,
50        )
51        return -log_prob.sum(dim=-1).mean()

53class scVI(nn.Module):
54    """scVI (Lopez 2018) — Variational Autoencoder for scRNA-seq.
55    
56    Architecture:
57        Encoder: counts (B, G) + batch (B, B_dim) → (μ_z, σ_z) → latent z (B, latent_dim)
58        Decoder: z + batch → (μ, π) → ZINB likelihood
59    
60    Latent z captures cell-type identity, batch-corrected via conditional encoder.
61    """
62    def __init__(self, n_genes: int = 20000, latent_dim: int = 30,
63                 hidden_dim: int = 256, n_batch: int = 10):
64        super().__init__()
65        self.n_genes = n_genes
66        self.latent_dim = latent_dim
67        
68        # Encoder: (counts, batch_onehot) → (μ_z, log_var_z)
69        encoder_input_dim = n_genes + n_batch
70        self.encoder = nn.Sequential(
71            nn.Linear(encoder_input_dim, hidden_dim),
72            nn.LayerNorm(hidden_dim),
73            nn.ReLU(),
74            nn.Dropout(0.1),
75            nn.Linear(hidden_dim, hidden_dim),
76            nn.LayerNorm(hidden_dim),
77            nn.ReLU(),
78        )
79        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
80        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)
81        
82        # Decoder: (z, batch_onehot) → (μ, log_θ, π)
83        decoder_input_dim = latent_dim + n_batch
84        self.decoder = nn.Sequential(
85            nn.Linear(decoder_input_dim, hidden_dim),
86            nn.LayerNorm(hidden_dim),
87            nn.ReLU(),
88            nn.Dropout(0.1),
89            nn.Linear(hidden_dim, n_genes),
90        )
91        # Per-gene dispersion (learnable)
92        self.theta = nn.Parameter(torch.randn(n_genes))
93        # Dropout (per-cell, per-gene)
94        self.dropout = nn.Linear(decoder_input_dim, n_genes)
95    
96    def encode(self, x: torch.Tensor, batch: torch.Tensor) -> Tuple[torch.Tensor, torch.Tensor]:
97        """Encode (counts, batch) → (μ, log_var)."""
98        h = torch.cat([x, batch], dim=-1)
99        h = self.encoder(h)
100        return self.fc_mu(h), self.fc_logvar(h)
101    
102    def reparameterize(self, mu: torch.Tensor, logvar: torch.Tensor) -> torch.Tensor:
103        """Reparameterisation trick: z = mu + std * eps."""
104        std = torch.exp(0.5 * logvar)
105        eps = torch.randn_like(std)
106        return mu + eps * std
107    
108    def decode(self, z: torch.Tensor, batch: torch.Tensor) -> Dict[str, torch.Tensor]:
109        """Decode (z, batch) → (μ, θ, π) for ZINB likelihood."""
110        h = torch.cat([z, batch], dim=-1)
111        # Mean (positive)
112        mu = torch.exp(self.decoder(h))  # (B, G)
113        # Dispersion (per-gene, positive)
114        theta = torch.exp(self.theta)  # (G,)
115        # Dropout (per-cell, per-gene)
116        pi = torch.sigmoid(self.dropout(h))  # (B, G)
117        return {'mu': mu, 'theta': theta, 'pi': pi}
118    
119    def forward(self, x: torch.Tensor, batch: torch.Tensor) -> Dict[str, torch.Tensor]:
120        """Forward pass.
121        
122        Args:
123            x: (B, G) gene count matrix (sparse-encoded as dense for simplicity)
124            batch: (B, n_batch) one-hot batch IDs
125        
126        Returns: dict with 'latent', 'mu', 'theta', 'pi', 'kl'
127        """
128        mu_z, logvar_z = self.encode(x, batch)
129        z = self.reparameterize(mu_z, logvar_z)
130        out = self.decode(z, batch)
131        out['latent'] = z
132        out['mu_z'] = mu_z
133        out['logvar_z'] = logvar_z
134        # KL divergence: 0.5 * Σ (1 + logvar - mu² - exp(logvar))
135        out['kl'] = -0.5 * torch.sum(1 + logvar_z - mu_z.pow(2) - logvar_z.exp(), dim=-1)
136        return out
137    
138    def loss(self, x: torch.Tensor, batch: torch.Tensor) -> torch.Tensor:
139        """scVI loss: ZINB reconstruction + KL."""
140        out = self.forward(x, batch)
141        # Reconstruction (ZINB)
142        zinb = ZINBLoss()
143        recon_loss = zinb(x, out['mu'], out['theta'], out['pi'])
144        # KL
145        kl_loss = out['kl'].mean()
146        return recon_loss + 1e-4 * kl_loss

152class WNN(nn.Module):
153    """WNN (Hao 2021, Seurat v4) — Weighted Nearest Neighbours integration.
154    
155    For paired multi-modal data (e.g. 10x Multiome: RNA + ATAC on same cell):
156        1. Embed RNA via scVI (this class wraps)
157        2. Embed ATAC via LSI (TF-IDF + SVD)
158        3. For each cell: find k-NN in each modality
159        4. Compute per-cell modality weights (softmax over k-NN quality)
160        5. Combined k-NN graph: rank by w_RNA · sim_RNA + w_ATAC · sim_ATAC
161    
162    Output: cell × cell WNN graph for clustering / UMAP.
163    """
164    def __init__(self, rna_dim: int, atac_dim: int, k: int = 30):
165        super().__init__()
166        self.k = k
167        # Modality embeddings (pre-computed by scVI / LSI)
168        # Here: learned projectors for demo
169        self.rna_proj = nn.Linear(rna_dim, 30)
170        self.atac_proj = nn.Linear(atac_dim, 30)
171        # Per-cell modality weights (softmax over 2 modalities)
172        self.weight_scorer = nn.Sequential(
173            nn.Linear(30 * 2, 16),
174            nn.ReLU(),
175            nn.Linear(16, 2),  # (w_RNA, w_ATAC)
176        )
177    
178    def forward(self, rna_emb: torch.Tensor, atac_emb: torch.Tensor) -> Dict[str, torch.Tensor]:
179        """Compute WNN graph.
180        
181        Args:
182            rna_emb: (N, rna_dim) RNA embeddings
183            atac_emb: (N, atac_dim) ATAC embeddings
184        
185        Returns: dict with 'wnn_graph' (N, N), 'modality_weights' (N, 2)
186        """
187        # Project to common space
188        rna_proj = self.rna_proj(rna_emb)  # (N, 30)
189        atac_proj = self.atac_proj(atac_emb)  # (N, 30)
190        
191        # Normalise for cosine similarity
192        rna_proj = F.normalize(rna_proj, dim=-1)
193        atac_proj = F.normalize(atac_proj, dim=-1)
194        
195        # Per-cell modality weights
196        combined = torch.cat([rna_proj, atac_proj], dim=-1)  # (N, 60)
197        modality_weights = F.softmax(self.weight_scorer(combined), dim=-1)  # (N, 2)
198        
199        # Compute similarities (N, N)
200        sim_rna = rna_proj @ rna_proj.T  # cosine similarity
201        sim_atac = atac_proj @ atac_proj.T
202        
203        # WNN: weighted combination per cell
204        # w_cell = (w_RNA, w_ATAC) per cell — broadcast to (N, 1, 2)
205        w = modality_weights.unsqueeze(1)  # (N, 1, 2)
206        # sim: (N, N, 2) where dim=-1 is (RNA, ATAC)
207        sim_stack = torch.stack([sim_rna, sim_atac], dim=-1)  # (N, N, 2)
208        wnn = (w * sim_stack).sum(dim=-1)  # (N, N)
209        
210        return {'wnn_graph': wnn, 'modality_weights': modality_weights}

216class RNAVelocitySolver:
217    """RNA velocity (La Manno 2018, Bergen 2020 scVelo).
218    
219    For each gene per cell:
220        u = unspliced mRNA (intronic reads)
221        s = spliced mRNA (exonic reads)
222        
223    Kinetic ODE:
224        du/dt = α - β·u
225        ds/dt = β·u - γ·s
226        
227    Velocity:
228        v = ds/dt = β·u - γ·s  (cell-state transition rate)
229    
230    Production: scVelo (Bergen 2020) uses EM for kinetic parameter estimation.
231    """
232    @staticmethod
233    def estimate_gamma(unspliced: torch.Tensor, spliced: torch.Tensor) -> torch.Tensor:
234        """Estimate γ per gene via linear regression on steady-state cells.
235        
236        At steady state: u = (γ/β) · s
237        → Linear regression: u = slope · s + offset
238        → slope ≈ γ/β (assuming β=1)
239        
240        Args:
241            unspliced: (N_cells, N_genes) intronic counts
242            spliced: (N_cells, N_genes) exonic counts
243        
244        Returns: gamma (N_genes,)
245        """
246        # Per-gene linear regression via least squares
247        # u = γ · s + offset
248        n_cells, n_genes = unspliced.shape
249        
250        # Center: subtract means
251        u_mean = unspliced.mean(dim=0)  # (N_genes,)
252        s_mean = spliced.mean(dim=0)
253        u_centered = unspliced - u_mean
254        s_centered = spliced - s_mean
255        
256        # γ = (s · u) / (s · s) per gene
257        numerator = (s_centered * u_centered).sum(dim=0)  # (N_genes,)
258        denominator = (s_centered ** 2).sum(dim=0) + 1e-8
259        gamma = numerator / denominator  # (N_genes,)
260        return torch.clamp(gamma, min=0.01, max=10.0)
261    
262    @staticmethod
263    def compute_velocity(unspliced: torch.Tensor, spliced: torch.Tensor,
264                         gamma: torch.Tensor = None, beta: float = 1.0) -> torch.Tensor:
265        """Compute per-cell velocity.
266        
267        v = β · u - γ · s  (per gene, per cell)
268        
269        Args:
270            unspliced: (N_cells, N_genes)
271            spliced: (N_cells, N_genes)
272            gamma: (N_genes,) — if None, estimate from data
273            beta: scalar splicing rate
274        
275        Returns: (N_cells, N_genes) velocity per gene per cell
276        """
277        if gamma is None:
278            gamma = RNAVelocitySolver.estimate_gamma(unspliced, spliced)
279        # v = β · u - γ · s
280        v = beta * unspliced - gamma.unsqueeze(0) * spliced
281        return v
282    
283    @staticmethod
284    def project_velocity_to_embedding(velocity: torch.Tensor, embedding: torch.Tensor,
285                                       neighbour_graph: torch.Tensor) -> torch.Tensor:
286        """Project gene-space velocity to embedding space (UMAP / PCA).
287        
288        For each cell, average velocity of k nearest neighbours.
289        
290        Args:
291            velocity: (N_cells, N_genes) per-gene velocity
292            embedding: (N_cells, 2) 2D embedding (UMAP)
293            neighbour_graph: (N_cells, k) indices of k-NN
294        
295        Returns: (N_cells, 2) velocity arrows in embedding space
296        """
297        N, k = neighbour_graph.shape
298        # For each cell, compute transition probability to each neighbour
299        # (based on cosine similarity of velocity vectors)
300        # Then sum: weighted displacement in embedding space
301        arrows = torch.zeros(N, 2)
302        for i in range(N):
303            nbrs = neighbour_graph[i]  # (k,)
304            # Velocity of cell i in gene space
305            v_i = velocity[i]  # (N_genes,)
306            # Cosine sim of v_i with delta_embedding to each neighbour
307            delta_emb = embedding[nbrs] - embedding[i]  # (k, 2)
308            # Project v_i onto delta_emb (simplified: just use cosine sim of velocity)
309            # Production: project via kernel matrix (scVelo uses Gaussian kernel)
310            weights = F.cosine_similarity(v_i.unsqueeze(0).expand(k, -1),
311                                            delta_emb, dim=-1)  # (k,)
312            weights = F.softmax(weights, dim=0)  # normalise
313            # Weighted sum of deltas
314            arrows[i] = (weights.unsqueeze(-1) * delta_emb).sum(dim=0)
315        return arrows

318# 4. Harmony — fast batch correction
319# ============================================================
320 
321class Harmony(nn.Module):
322    """Harmony (Korsunsky 2019) — fast batch correction.
323    
324    Algorithm:
325        1. PCA on combined data (all batches)
326        2. Initialise k cluster centres
327        3. For each iteration:
328           a. Soft cluster assignment per cell (responsibilities)
329           b. For each cell: subtract batch-specific mean
330           c. Re-assign clusters
331    
332    Converges in &lt;10 iterations, ~1000× faster than scVI's full VAE training.
333    """
334    def __init__(self, n_clusters: int = 20, max_iter: int = 10):
335        super().__init__()
336        self.n_clusters = n_clusters
337        self.max_iter = max_iter
338        # Cluster centres (learned)
339        self.cluster_centres = nn.Parameter(torch.randn(n_clusters, 30))
340        # Batch correction: per-batch means
341        # (computed at runtime, not stored)
342    
343    def forward(self, embeddings: torch.Tensor, batch_ids: torch.Tensor) -> torch.Tensor:
344        """Harmony batch correction.
345        
346        Args:
347            embeddings: (N, 30) PCA-reduced cell embeddings
348            batch_ids: (N,) integer batch IDs
349        
350        Returns: (N, 30) batch-corrected embeddings
351        """
352        corrected = embeddings.clone()
353        for _ in range(self.max_iter):
354            # Soft cluster assignment: cosine sim to centres
355            sim = F.cosine_similarity(
356                corrected.unsqueeze(1),  # (N, 1, 30)
357                self.cluster_centres.unsqueeze(0),  # (1, K, 30)
358                dim=-1
359            )  # (N, K)
360            responsibilities = F.softmax(sim * 10, dim=-1)  # (N, K) — temperature 10
361            
362            # For each cell, compute batch-specific mean
363            for batch_id in torch.unique(batch_ids):
364                mask = (batch_ids == batch_id)
365                # Weighted mean of cluster centres for this batch
366                weighted_centres = responsibilities[mask] @ self.cluster_centres  # (n_batch_cells, 30)
367                batch_mean = weighted_centres.mean(dim=0)  # (30,)
368                # Subtract batch mean (correction)
369                corrected[mask] = embeddings[mask] - batch_mean + self.cluster_centres.mean(dim=0)
370        
371        return corrected

Insight
scVI's VAE is matrix factorisation (X = U·V^T where U=cell embeddings, V=gene factors). WNN is multi-matrix factorisation (X_RNA + X_ATAC). RNA velocity adds temporal information via kinetic ODE. The same matrix factorisation principle underlies recommender systems (Netflix), NLP (word2vec), and single-cell analysis — different domains, same math.

scVI IS non-negative matrix factorisation with VAE. The cell × gene count matrix X (1M × 20K) is decomposed as X ≈ Decoder(z) where z is the 30-dim latent. This is structurally identical to NMF (Lee & Seung 1999, popularised by Netflix Prize 2009) — decompose a high-dim matrix into low-dim factors. The difference: scVI's VAE uses a non-linear decoder (vs NMF's linear), and ZINB likelihood (vs NMF's Gaussian). The platform's recommender system (recommend products to users based on their latent) is the same algorithm as cell-type identification (recommend cell type to a cell based on its latent) — different domain, same math.

WNN is multi-matrix factorisation with shared latent. For paired multi-modal data (RNA + ATAC on same cell), WNN finds a shared latent space that explains both modalities. This is structurally identical to MOFA+ (ADR-039 multi-omics) — both decompose multi-matrix data into shared + modality-specific factors. The difference: WNN uses k-NN-based integration (graph), MOFA+ uses Bayesian factor analysis (matrix). The principle is the same: shared structure across modalities. The platform's multi-modal RAG (ADR-033 SigLIP + ADR-035 ChemBERTa + ADR-034 ESM-2) is the same pattern — different encoder per modality, shared embedding space.

RNA velocity IS ODE-constrained matrix factorisation. The kinetic ODE du/dt = α - β·u, ds/dt = β·u - γ·s constrains the temporal evolution of (u, s) per gene per cell.
