HMM Viterbi math — finding genes via dynamic programming
mathematics
A Hidden Markov Model represents DNA as a sequence of hidden states (exon/intron/UTR/intergenic) that emit observable nucleotides. Viterbi finds the most likely state path — the maximum a posteriori (MAP) estimate. The DP recurrence is the same as Bellman-Ford shortest-path on the state graph.

V[t, s] = maxs' ( V[t-1, s'] · P(s|s') · P(obst|s) )

DP: best score to reach state s at time t = best previous score × transition × emission. Complexity O(L·S²) — for L=10⁶, S=4: 16M operations.

Emissions P(obs|state)

E: A=0.25 C=0.25 G=0.30 T=0.20

I: T=0.65 (T-rich introns)

Each state has a different nucleotide distribution. Exons slightly G-biased (codons), introns T-rich (splice signals).

Transitions P(s|s')

E→E: 0.90 (stay in exon)

E→I: 0.08 (enter intron)

Exons are long (avg 150bp), so E→E is high. Intergenic regions are very long, so S→S is 0.95.

5th-order HMM (GENSCAN)

S = 4⁵ = 1024 states

Burge & Karlin 1997: emissions depend on previous 5 nucleotides — captures codon periodicity in exons. Still tractable: 10⁹ ops per Mb.

BLOSUM matrix derivation — log-odds substitution scores
mathematics
BLOSUM (BLOcks SUbstitution Matrix, Henikoff & Henikoff 1992) scores amino acid substitutions based on observed frequencies in aligned protein blocks. The score s(i,j) = log2(p_ij / (p_i·p_j)) — the log-odds ratio. Positive scores = substitutions more frequent than expected by chance (conservative), negative = less frequent (radical). BLOSUM62 uses blocks with ≥62% identity.

s(i, j) = log2( pij / (pi · pj) )  ×  2

p_ij = observed frequency of i-j pair in aligned blocks. p_i, p_j = background frequencies. ×2 to convert to half-bit units (BLOSUM62 convention).

BLOSUM62 example scores:

  • s(A, A) = +4 — alanine-alanine very common (small, hydrophobic)
  • s(R, R) = +5 — arginine-arginine (positive charge, conserved)
  • s(A, R) = -1 — alanine→arginine rare (different chemistry)
  • s(D, E) = +2 — aspartate→glutamate (both acidic, conservative)
  • s(W, W) = +11 — tryptophan-tryptophan (largest, rarest)

The matrix is symmetric. Used in BLAST, Smith-Waterman alignment. The threshold '62' in BLOSUM62 means blocks clustered at ≥62% identity were used — higher numbers (BLOSUM90) catch closer homologs, lower (BLOSUM45) catch distant.

Modern scientific papers — ENCODE, GTEx, UK Biobank, CRISPR
The 4 papers that defined modern genetics: (1) ENCODE (2012, Nature 489.7414 — 1.3M candidate regulatory elements in the human genome, 80% of the genome has biochemical function). (2) GTEx (2020, Science 369.6509 — eQTLs in 49 tissues, SNPs that affect gene expression). (3) UK Biobank (2023, Nature 622 — 500K whole-genome sequences, 4K phenotype fields). (4) Doench 2016 (Nature Methods — CRISPR guide design with logistic regression on 60-mer features).

ENCODE (Encyclopedia of DNA Elements, 2012 + 2020): Mapped 1.3M candidate cis-regulatory elements (cCREs) — promoters, enhancers, insulators. Result: ~80% of the genome has some biochemical function (vs the old 'junk DNA' view), though 'function' is debated. HPC: 1.6TB of ChIP-seq, DNase-seq, RNA-seq data per biosample, processed on the ENCODE Data Coordination Center. Connects to ADR-037: regulatory SNPs from GWAS are cross-referenced against ENCODE annotations to identify mechanism.

GTEx (Genotype-Tissue Expression, 2020): Identified eQTLs — SNPs that affect gene expression — in 49 tissues from 838 post-mortem donors. ~16K genes have at least one eQTL. Result: most GWAS hits (95%) are in non-coding regions; eQTL mapping reveals which tissue a variant acts in. Key for ADR-037: a GWAS hit in tissue X can be linked to a specific gene via GTEx eQTL data.

UK Biobank (Half-million WGS, 2023): 500,000 whole-genome sequences from British volunteers, plus 4,000 phenotype fields (imaging, blood biomarkers, lifestyle). The largest open-access genetics dataset. Enables GWAS at unprecedented power — variants with effect sizes 10× smaller than previously detectable. HPC: 165TB of WGS data, processed on DNAnexus (150M CPU-hours). The UKB pipeline (Wright et al. 2021) is the template for national-scale genomics.

Doench 2016 (CRISPR guide design): Trained a logistic regression on 1,841 guides with measured on-target activity. Features: 30nt context (20nt guide + 4nt PAM + 3nt 5' extension + 3nt 3' extension). The model is a simple linear model on one-hot features — interpretable (shows that G at position 20 of the guide + NGG PAM = strongest cut). Production: every CRISPR experiment uses this score or its successor (DeepCRISPR).

11class HMM:
12    """Hidden Markov Model with Viterbi decoding.
13    
14    States: E(exon), I(intron), S(intergenic), U(UTR)
15    Emissions: ACGT (one per state)
16    Transitions: state-to-state probabilities
17    
18    Production: GENSCAN (Burge & Karlin 1997) uses 5th-order HMM
19    where emissions depend on the previous 5 nucleotides — captures
20    codon periodicity in exons.
21    """
22    def __init__(self, emissions: Dict[str, Dict[str, float]],
23                 transitions: Dict[str, Dict[str, float]],
24                 initial: Dict[str, float]):
25        self.states = list(emissions.keys())
26        self.emissions = emissions
27        self.transitions = transitions
28        self.initial = initial
29    
30    def viterbi(self, observations: str) -> Tuple[str, float]:
31        """Viterbi: find the most likely state path. O(L·S²)."""
32        L = len(observations)
33        S = len(self.states)
34        
35        # Use log-probs to avoid underflow
36        V = torch.full((L, S), -float('inf'))
37        bp = torch.zeros((L, S), dtype=torch.long)
38        
39        # Init
40        for si, s in enumerate(self.states):
41            emit_p = self.emissions[s].get(observations[0], 1e-10)
42            init_p = self.initial.get(s, 1e-10)
43            V[0, si] = math.log(init_p) + math.log(emit_p)
44        
45        # DP
46        for t in range(1, L):
47            obs = observations[t]
48            for si, s in enumerate(self.states):
49                emit_p = self.emissions[s].get(obs, 1e-10)
50                log_emit = math.log(emit_p)
51                # Best previous state
52                scores = V[t-1] + torch.tensor([
53                    math.log(self.transitions[sp].get(s, 1e-10))
54                    for sp in self.states
55                ])
56                best_prev = scores.argmax()
57                V[t, si] = scores[best_prev] + log_emit
58                bp[t, si] = best_prev
59        
60        # Backtrack
61        path = [V[L-1].argmax().item()]
62        for t in range(L-1, 0, -1):
63            path.append(bp[t, path[-1]].item())
64        path.reverse()
65        
66        state_path = ''.join(self.states[si] for si in path)
67        return state_path, V[L-1].max().item()
68    
69    def forward(self, observations: str) -> float:
70        """Forward algorithm: P(observations) — sum over all paths.
71        
72        Used for parameter learning (Baum-Welch).
73        """
74        L = len(observations)
75        S = len(self.states)
76        
77        alpha = torch.zeros(L, S)
78        for si, s in enumerate(self.states):
79            alpha[0, si] = self.initial.get(s, 0) * self.emissions[s].get(observations[0], 0)
80        
81        for t in range(1, L):
82            for si, s in enumerate(self.states):
83                for sp, s_prev in enumerate(self.states):
84                    alpha[t, si] += alpha[t-1, sp] * self.transitions[s_prev].get(s, 0)
85                alpha[t, si] *= self.emissions[s].get(observations[t], 0)
86        
87        return alpha[L-1].sum().item()

200class GWAS:
201    """Genome-Wide Association Study via logistic regression.
202    
203    For each SNP: P(disease | SNP) = σ(β_0 + β·SNP + γ·covariates)
204    Test H_0: β = 0 via Wald test (z = β_hat / SE(β_hat)).
205    
206    Bonferroni correction: α / N_SNPs (e.g. 5e-8 for 10M SNPs).
207    
208    Production: PLINK 2.0 (C++) or BOLT-LMM (mixed model for stratification).
209    """
210    def __init__(self, n_snps: int = 10_000_000, alpha: float = 5e-8):
211        self.n_snps = n_snps
212        self.alpha = alpha  # genome-wide significance threshold
213    
214    def logistic_regression(self, X: torch.Tensor, y: torch.Tensor,
215                            max_iter: int = 100) -> torch.Tensor:
216        """Fit logistic regression via IRLS (iteratively reweighted least squares).
217        
218        Minimise: -log L(β) = -Σ[y·log(σ(Xβ)) + (1-y)·log(1-σ(Xβ))]
219        """
220        n, p = X.shape
221        beta = torch.zeros(p, dtype=X.dtype, requires_grad=True)
222        opt = torch.optim.LBFGS([beta], max_iter=max_iter, line_search_fn='strong_wolfe')
223        
224        def closure():
225            opt.zero_grad()
226            logits = X @ beta
227            loss = F.binary_cross_entropy_with_logits(logits, y)
228            loss.backward()
229            return loss
230        
231        opt.step(closure)
232        return beta.detach()
233    
234    def wald_test(self, beta: torch.Tensor, X: torch.Tensor,
235                  y: torch.Tensor, idx: int = 1) -> Tuple[float, float]:
236        """Wald test: z = β_hat / SE(β_hat).
237        
238        SE(β) ≈ sqrt(diag(cov(β_hat))) where cov ≈ (X^T · diag(p(1-p)) · X)^-1
239        """
240        with torch.no_grad():
241            logits = X @ beta
242            p = torch.sigmoid(logits)
243            W = p * (1 - p)  # weights
244            # Fisher information: X^T W X
245            fisher = X.T @ (W.unsqueeze(-1) * X)
246            cov = torch.linalg.inv(fisher)
247            se = torch.sqrt(torch.diag(cov))
248        
249        z = beta[idx] / se[idx]
250        p_value = 2 * (1 - torch.distributions.Normal(0, 1).cdf(torch.abs(z)))
251        return z.item(), p_value.item()
252    
253    def fit_per_snp(self, genotypes: torch.Tensor, phenotypes: torch.Tensor,
254                    covariates: torch.Tensor = None) -> List[Dict]:
255        """Fit logistic regression per SNP. Returns p-value per SNP.
256        
257        Args:
258            genotypes: (N, M) genotype matrix (0/1/2)
259            phenotypes: (N,) 0/1 case/control
260            covariates: (N, K) covariates (age, sex, PCs) — optional
261        
262        Returns: list of {snp_idx, beta, z, p_value, significant}
263        """
264        N, M = genotypes.shape
265        if covariates is None:
266            covariates = torch.ones(N, 1)
267        
268        results = []
269        for snp_idx in range(M):
270            X = torch.cat([
271                covariates,
272                genotypes[:, snp_idx:snp_idx+1],
273            ], dim=1).double()
274            y = phenotypes.double()
275            
276            beta = self.logistic_regression(X, y)
277            z, p = self.wald_test(beta, X, y, idx=covariates.shape[1])
278            
279            results.append({
280                'snp_idx': snp_idx,
281                'beta': beta[covariates.shape[1]].item(),
282                'z': z,
283                'p_value': p,
284                'significant': p < self.alpha,
285            })
286        
287        return results

HMM Viterbi math — finding genes via dynamic programming
mathematics
A Hidden Markov Model represents DNA as a sequence of hidden states (exon/intron/UTR/intergenic) that emit observable nucleotides. Viterbi finds the most likely state path — the maximum a posteriori (MAP) estimate. The DP recurrence is the same as Bellman-Ford shortest-path on the state graph.

V[t, s] = maxs' ( V[t-1, s'] · P(s|s') · P(obst|s) )

DP: best score to reach state s at time t = best previous score × transition × emission. Complexity O(L·S²) — for L=10⁶, S=4: 16M operations.

Emissions P(obs|state)

E: A=0.25 C=0.25 G=0.30 T=0.20

I: T=0.65 (T-rich introns)

Each state has a different nucleotide distribution. Exons slightly G-biased (codons), introns T-rich (splice signals).

Transitions P(s|s')

E→E: 0.90 (stay in exon)

E→I: 0.08 (enter intron)

Exons are long (avg 150bp), so E→E is high. Intergenic regions are very long, so S→S is 0.95.

5th-order HMM (GENSCAN)

S = 4⁵ = 1024 states

Burge & Karlin 1997: emissions depend on previous 5 nucleotides — captures codon periodicity in exons. Still tractable: 10⁹ ops per Mb.

BLOSUM matrix derivation — log-odds substitution scores
mathematics
BLOSUM (BLOcks SUbstitution Matrix, Henikoff & Henikoff 1992) scores amino acid substitutions based on observed frequencies in aligned protein blocks. The score s(i,j) = log2(p_ij / (p_i·p_j)) — the log-odds ratio. Positive scores = substitutions more frequent than expected by chance (conservative), negative = less frequent (radical). BLOSUM62 uses blocks with ≥62% identity.

s(i, j) = log2( pij / (pi · pj) )  ×  2

p_ij = observed frequency of i-j pair in aligned blocks. p_i, p_j = background frequencies. ×2 to convert to half-bit units (BLOSUM62 convention).

BLOSUM62 example scores:

  • s(A, A) = +4 — alanine-alanine very common (small, hydrophobic)
  • s(R, R) = +5 — arginine-arginine (positive charge, conserved)
  • s(A, R) = -1 — alanine→arginine rare (different chemistry)
  • s(D, E) = +2 — aspartate→glutamate (both acidic, conservative)
  • s(W, W) = +11 — tryptophan-tryptophan (largest, rarest)

The matrix is symmetric. Used in BLAST, Smith-Waterman alignment. The threshold '62' in BLOSUM62 means blocks clustered at ≥62% identity were used — higher numbers (BLOSUM90) catch closer homologs, lower (BLOSUM45) catch distant.

11class HMM:
12    """Hidden Markov Model with Viterbi decoding.
13    
14    States: E(exon), I(intron), S(intergenic), U(UTR)
15    Emissions: ACGT (one per state)
16    Transitions: state-to-state probabilities
17    
18    Production: GENSCAN (Burge & Karlin 1997) uses 5th-order HMM
19    where emissions depend on the previous 5 nucleotides — captures
20    codon periodicity in exons.
21    """
22    def __init__(self, emissions: Dict[str, Dict[str, float]],
23                 transitions: Dict[str, Dict[str, float]],
24                 initial: Dict[str, float]):
25        self.states = list(emissions.keys())
26        self.emissions = emissions
27        self.transitions = transitions
28        self.initial = initial
29    
30    def viterbi(self, observations: str) -> Tuple[str, float]:
31        """Viterbi: find the most likely state path. O(L·S²)."""
32        L = len(observations)
33        S = len(self.states)
34        
35        # Use log-probs to avoid underflow
36        V = torch.full((L, S), -float('inf'))
37        bp = torch.zeros((L, S), dtype=torch.long)
38        
39        # Init
40        for si, s in enumerate(self.states):
41            emit_p = self.emissions[s].get(observations[0], 1e-10)
42            init_p = self.initial.get(s, 1e-10)
43            V[0, si] = math.log(init_p) + math.log(emit_p)
44        
45        # DP
46        for t in range(1, L):
47            obs = observations[t]
48            for si, s in enumerate(self.states):
49                emit_p = self.emissions[s].get(obs, 1e-10)
50                log_emit = math.log(emit_p)
51                # Best previous state
52                scores = V[t-1] + torch.tensor([
53                    math.log(self.transitions[sp].get(s, 1e-10))
54                    for sp in self.states
55                ])
56                best_prev = scores.argmax()
57                V[t, si] = scores[best_prev] + log_emit
58                bp[t, si] = best_prev
59        
60        # Backtrack
61        path = [V[L-1].argmax().item()]
62        for t in range(L-1, 0, -1):
63            path.append(bp[t, path[-1]].item())
64        path.reverse()
65        
66        state_path = ''.join(self.states[si] for si in path)
67        return state_path, V[L-1].max().item()
68    
69    def forward(self, observations: str) -> float:
70        """Forward algorithm: P(observations) — sum over all paths.
71        
72        Used for parameter learning (Baum-Welch).
73        """
74        L = len(observations)
75        S = len(self.states)
76        
77        alpha = torch.zeros(L, S)
78        for si, s in enumerate(self.states):
79            alpha[0, si] = self.initial.get(s, 0) * self.emissions[s].get(observations[0], 0)
80        
81        for t in range(1, L):
82            for si, s in enumerate(self.states):
83                for sp, s_prev in enumerate(self.states):
84                    alpha[t, si] += alpha[t-1, sp] * self.transitions[s_prev].get(s, 0)
85                alpha[t, si] *= self.emissions[s].get(observations[t], 0)
86        
87        return alpha[L-1].sum().item()

93class CRISPRGuideDesigner:
94    """CRISPR-Cas9 guide RNA design.
95    
96    On-target score: Doench 2016 (Nature Methods) — logistic regression on
97    30nt features (20nt guide + 4nt PAM + 3nt context).
98    
99    Off-target score: Hsu 2013 (Nature Biotechnology) — weighted mismatch
100    penalties, position-dependent.
101    
102    Production: Python CRISPResso2, Benchling cloud, or in-house on Spark.
103    """
104    def __init__(self):
105        # Simplified weights (real Doench 2016 has ~3000 features)
106        # Position-dependent: mismatches at 3' end are more tolerated (PAM-proximal)
107        self.position_weights = torch.tensor([
108            0.10, 0.10, 0.10, 0.10, 0.10, 0.10, 0.10, 0.10, 0.10, 0.10,
109            0.15, 0.15, 0.20, 0.25, 0.30, 0.40, 0.50, 0.60, 0.80, 1.00,  # 3' end heavy
110        ])
111        # PAM weights (NGG preferred, NAG weaker)
112        self.pam_scores = {'NGG': 1.0, 'NAG': 0.3, 'NGA': 0.1, 'other': 0.0}
113        
114        self.on_target_model = nn.Sequential(
115            nn.Linear(80, 32),  # 20nt one-hot × 4 = 80 features
116            nn.ReLU(),
117            nn.Linear(32, 1),
118            nn.Sigmoid(),
119        )
120    
121    def on_target_score(self, guide_rna: str) -> float:
122        """Doench 2016 on-target score (simplified).
123        
124        Args:
125            guide_rna: 20nt sequence
126        
127        Returns: float [0, 1] — higher = better guide
128        """
129        # One-hot encode
130        nuc_to_idx = {'A': 0, 'C': 1, 'G': 2, 'T': 3}
131        one_hot = torch.zeros(20, 4)
132        for i, nuc in enumerate(guide_rna.upper()):
133            if nuc in nuc_to_idx:
134                one_hot[i, nuc_to_idx[nuc]] = 1.0
135        
136        # Logistic regression on one-hot features
137        score = self.on_target_model(one_hot.flatten().unsqueeze(0))
138        return score.item()
139    
140    def off_target_score(self, guide: str, off_target: str) -> float:
141        """Hsu 2013 MIT off-target score.
142        
143        Penalties for mismatches, weighted by position (3' end more tolerated).
144        
145        Formula: score = Π (1 - w_i · mm_i) for each position i
146        """
147        if len(guide) != len(off_target):
148            return 0.0
149        score = 1.0
150        for i, (g, o) in enumerate(zip(guide.upper(), off_target.upper())):
151            if g != o:
152                # Mismatch — apply position-dependent penalty
153                score *= (1 - self.position_weights[i].item())
154        return score
155

200class GWAS:
201    """Genome-Wide Association Study via logistic regression.
202    
203    For each SNP: P(disease | SNP) = σ(β_0 + β·SNP + γ·covariates)
204    Test H_0: β = 0 via Wald test (z = β_hat / SE(β_hat)).
205    
206    Bonferroni correction: α / N_SNPs (e.g. 5e-8 for 10M SNPs).
207    
208    Production: PLINK 2.0 (C++) or BOLT-LMM (mixed model for stratification).
209    """
210    def __init__(self, n_snps: int = 10_000_000, alpha: float = 5e-8):
211        self.n_snps = n_snps
212        self.alpha = alpha  # genome-wide significance threshold
213    
214    def logistic_regression(self, X: torch.Tensor, y: torch.Tensor,
215                            max_iter: int = 100) -> torch.Tensor:
216        """Fit logistic regression via IRLS (iteratively reweighted least squares).
217        
218        Minimise: -log L(β) = -Σ[y·log(σ(Xβ)) + (1-y)·log(1-σ(Xβ))]
219        """
220        n, p = X.shape
221        beta = torch.zeros(p, dtype=X.dtype, requires_grad=True)
222        opt = torch.optim.LBFGS([beta], max_iter=max_iter, line_search_fn='strong_wolfe')
223        
224        def closure():
225            opt.zero_grad()
226            logits = X @ beta
227            loss = F.binary_cross_entropy_with_logits(logits, y)
228            loss.backward()
229            return loss
230        
231        opt.step(closure)
232        return beta.detach()
233    
234    def wald_test(self, beta: torch.Tensor, X: torch.Tensor,
235                  y: torch.Tensor, idx: int = 1) -> Tuple[float, float]:
236        """Wald test: z = β_hat / SE(β_hat).
237        
238        SE(β) ≈ sqrt(diag(cov(β_hat))) where cov ≈ (X^T · diag(p(1-p)) · X)^-1
239        """
240        with torch.no_grad():
241            logits = X @ beta
242            p = torch.sigmoid(logits)
243            W = p * (1 - p)  # weights
244            # Fisher information: X^T W X
245            fisher = X.T @ (W.unsqueeze(-1) * X)
246            cov = torch.linalg.inv(fisher)
247            se = torch.sqrt(torch.diag(cov))
248        
249        z = beta[idx] / se[idx]
250        p_value = 2 * (1 - torch.distributions.Normal(0, 1).cdf(torch.abs(z)))
251        return z.item(), p_value.item()
252    
253    def fit_per_snp(self, genotypes: torch.Tensor, phenotypes: torch.Tensor,
254                    covariates: torch.Tensor = None) -> List[Dict]:
255        """Fit logistic regression per SNP. Returns p-value per SNP.
256        
257        Args:
258            genotypes: (N, M) genotype matrix (0/1/2)
259            phenotypes: (N,) 0/1 case/control
260            covariates: (N, K) covariates (age, sex, PCs) — optional
261        
262        Returns: list of {snp_idx, beta, z, p_value, significant}
263        """
264        N, M = genotypes.shape
265        if covariates is None:
266            covariates = torch.ones(N, 1)
267        
268        results = []
269        for snp_idx in range(M):
270            X = torch.cat([
271                covariates,
272                genotypes[:, snp_idx:snp_idx+1],
273            ], dim=1).double()
274            y = phenotypes.double()
275            
276            beta = self.logistic_regression(X, y)
277            z, p = self.wald_test(beta, X, y, idx=covariates.shape[1])
278            
279            results.append({
280                'snp_idx': snp_idx,
281                'beta': beta[covariates.shape[1]].item(),
282                'z': z,
283                'p_value': p,
284                'significant': p < self.alpha,
285            })
286        
287        return results
