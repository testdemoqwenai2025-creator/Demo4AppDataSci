Quantization math — the rounding error budget
mathematics
Quantisation is the lossy mapping of FP32 weights to a smaller codebook. The error e = x - dequant(quant(x)) is bounded by half the quantisation step size. Group quantisation reduces error by using per-group scales (each group has its own min/max). The MSE per group is minimised when the codebook is information-theoretically optimal for the weight distribution.

e(x) = x - dequant(quant(x))  ·  MSE = E[‖e‖²] = σ² / 12 (uniform)

Quantisation step Δ = 2·max/2^b where b = bits. Error bounded by Δ/2. Per-group Δ → lower MSE.

Group quantisation

scale_g = max(|w_g|)

Per-group scale → handles long-tail distributions. Group size 64-128 is the sweet spot.

NF4 (NormalFloat)

levels = 16 quantiles of N(0,1)

Information-optimal for normal weights. More levels near 0 (where weights are dense), fewer at the tails.

AWQ (activation-aware)

w' = s · w (top 1% channels)

Scale salient channels before quant → smaller relative error on the channels that matter for the output.

AWQ — why scaling salient channels works
mathematics
The activation-aware insight: not all weight channels matter equally. Channels with larger activation magnitudes contribute more to the layer's output. Scaling them up by (1+s) before quantisation reduces their relative error — the absolute error stays similar (same Δ), but it's now divided by a larger magnitude. AWQ finds the optimal s by grid search over a calibration set.

W' = s · W (salient channels),   e' = e / s  →  relative error ↓

Scaling up salient channels increases their magnitude, so the same absolute quantisation step Δ produces a smaller relative error on the output.

AWQ algorithm (4 steps):

  1. Calibrate: run 128 representative samples through the model, collect per-channel activation statistics (mean abs magnitude).
  2. Identify salient channels: top 1% by activation magnitude (these dominate the output variance).
  3. Grid search s ∈ [0, 1] (20 values): for each, scale salient channels ×(1+s), quantise+dequantise, measure MSE on the calibration set, pick best s.
  4. Apply final scale + standard INT4 group quantisation. Store: 4-bit codes + per-group FP16 scales + per-input-channel FP16 scaling factors.

At inference: scale input by channel_scale → matmul with dequantised weights → divide output by channel_scale. The scaling is transparent to the rest of the model.

10def build_nf4_grid() -> torch.Tensor:
11    """Build the NF4 grid: 16 quantiles of N(0,1) normalised to [-1,1].
12    
13    Information-theoretically optimal 4-bit grid for weights ~ N(0, σ²).
14    Used in QLoRA (ADR-023) for the backward pass.
15    """
16    # 16 quantiles at (i + 0.5) / 16 of N(0,1)
17    p = (torch.arange(16) + 0.5) / 16
18    # Inverse CDF via torch.erfinv: Φ^(-1)(p) = sqrt(2) * erfinv(2p - 1)
19    z = torch.sqrt(torch.tensor(2.0)) * torch.erfinv(2 * p - 1)
20    # Normalise to [-1, 1]
21    return z / z.abs().max()
22 
23NF4_GRID = build_nf4_grid()  # 16 levels in [-1, 1]
24 
25def quantize_nf4(weight: torch.Tensor, group_size: int = 64) -> Tuple[torch.Tensor, torch.Tensor]:
26    """Quantise a weight tensor to NF4.
27    
28    Returns:
29        codes: torch.uint8 (same shape, values 0-15) — 4-bit packed
30        scales: torch.float16 (shape [..., num_groups]) — one scale per group
31    
32    Memory savings: 4 bytes/param → 0.5 bytes/param + small scales = ~6.4× compression.
33    """
34    # Reshape into groups
35    *leading, total = weight.shape
36    num_groups = total // group_size
37    w = weight.reshape(*leading, num_groups, group_size)
38    
39    # Per-group scale = abs_max (since NF4 grid is normalised to [-1,1])
40    scales = w.abs().amax(dim=-1, keepdim=True).clamp(min=1e-10).to(torch.float16)
41    
42    # Normalise to [-1, 1]
43    w_norm = w / scales
44    
45    # Find nearest NF4 level (Euclidean)
46    # w_norm: [..., num_groups, group_size]
47    # NF4_GRID: [16]
48    # Compute distances: [..., num_groups, group_size, 16]
49    dist = (w_norm.unsqueeze(-1) - NF4_GRID.to(w_norm.dtype)).abs()
50    codes = dist.argmin(dim=-1).to(torch.uint8)
51    
52    return codes.reshape(weight.shape), scales.squeeze(-1)
53 
54def dequantize_nf4(codes: torch.Tensor, scales: torch.Tensor, group_size: int = 64) -> torch.Tensor:
55    """Dequantise NF4 codes back to FP16.
56    
57    Used in QLoRA to compute the forward pass: W = dequant_nf4(codes, scales)
58    """
59    *leading, total = codes.shape
60    num_groups = total // group_size
61    c = codes.reshape(*leading, num_groups, group_size)
62    s = scales.unsqueeze(-1).expand(*leading, num_groups, group_size)
63    
64    # Look up NF4 level for each code
65    w_norm = NF4_GRID.to(c.dtype)[c.long()]
66    
67    # Multiply by scale
68    return (w_norm * s).reshape(codes.shape).to(torch.float16)

74class AWQLinear(nn.Module):
75    """AWQ-quantised Linear layer for inference.
76    
77    Stores weights in 4-bit (with per-group scales) but applies activation-aware
78    scaling at dequantisation time. Saves 4× memory with <1% perplexity loss.
79    
80    Args (at construction):
81        in_features, out_features
82        group_size: quantisation group size (default 128)
83        scaling_factor: per-input-channel scale (calibrated offline)
84    
85    Forward:
86        x = scaling_factor * x   # scale UP salient channels
87        w = dequant_4bit(codes, scales)  # INT4 weight reconstruction
88        y = F.linear(x, w)  # standard matmul
89        y = y / scaling_factor  # scale back DOWN
90    """
91    def __init__(self, in_features: int, out_features: int, bias: bool = True,
92                 group_size: int = 128):
93        super().__init__()
94        self.in_features = in_features
95        self.out_features = out_features
96        self.group_size = group_size
97        
98        # 4-bit codes (packed as uint8, 2 codes per byte in production)
99        self.register_buffer(
100            "weight_codes",
101            torch.zeros(out_features, in_features, dtype=torch.uint8),
102        )
103        # Per-group scales (FP16)
104        num_groups = in_features // group_size
105        self.register_buffer(
106            "weight_scales",
107            torch.zeros(out_features, num_groups, dtype=torch.float16),
108        )
109        # Per-input-channel scaling factor (the AWQ trick)
110        self.register_buffer(
111            "channel_scale",
112            torch.ones(in_features, dtype=torch.float16),
113        )
114        if bias:
115            self.register_buffer("bias", torch.zeros(out_features, dtype=torch.float16))
116        else:
117            self.bias = None
118    
119    @torch.no_grad()
120    def quantize(self, weight: torch.Tensor, activation_stats: torch.Tensor,
121                 top_pct: float = 0.01):
122        """Calibrate: find salient channels + scaling factors, then quantise."""
123        # 1. Find salient channels (top 1% by activation magnitude)
124        num_salient = max(1, int(weight.shape[1] * top_pct))
125        _, salient_idx = activation_stats.abs().topk(num_salient)
126        salient_mask = torch.zeros(weight.shape[1], dtype=torch.bool)
127        salient_mask[salient_idx] = True
128        
129        # 2. Grid search for best scaling factor s
130        best_s, best_loss = 0.0, float('inf')
131        for s in torch.linspace(0, 1, 21):
132            # Scale up salient channels, scale down others (balance)
133            scale = torch.ones(weight.shape[1])
134            scale[salient_mask] *= (1 + s)
135            scale[~salient_mask] /= (1 + s * 0.5)
136            
137            # Quantise + dequantise, compute MSE
138            scaled_weight = weight * scale.unsqueeze(0)
139            codes, scales = quantize_nf4(scaled_weight, self.group_size)
140            deq = dequantize_nf4(codes, scales, self.group_size)
141            loss = ((scaled_weight.float() - deq.float()) ** 2).mean()
142            if loss < best_loss:
143                best_loss, best_s = loss, s.item()
144        
145        # 3. Apply best scaling
146        scale = torch.ones(weight.shape[1])
147        scale[salient_mask] *= (1 + best_s)
148        scale[~salient_mask] /= (1 + best_s * 0.5)
149        self.channel_scale = scale.to(torch.float16)
150        
151        # 4. Quantise the scaled weight
152        scaled_weight = weight * scale.unsqueeze(0)
153        codes, scales = quantize_nf4(scaled_weight, self.group_size)
154        self.weight_codes = codes
155        self.weight_scales = scales
156    
157    def forward(self, x: torch.Tensor) -> torch.Tensor:
158        # 1. Apply channel scaling (scale up salient inputs)
159        x = x.float() * self.channel_scale.float()
160        
161        # 2. Reconstruct weights in 4-bit, upcast to compute dtype
162        w = dequantize_nf4(self.weight_codes, self.weight_scales, self.group_size)
163        w = w.to(x.dtype)
164        
165        # 3. Standard matmul
166        out = torch.functional.F.linear(x, w)
167

179class Q4_K_M:
180    """llama.cpp Q4_K_M super-block quantisation.
181    
182    Layout (per super-block of 256 weights):
183        - 1 × 4-bit scale (FP16): overall block scale
184        - 2 × 6-bit scales (FP16, computed as min/max): per-sub-block scale  
185        - 256 × 4-bit codes: one per weight
186    
187    Effective bits/weight: 4 + (16 + 32) / 256 = 4.19 bits/weight
188    """
189    BLOCK_SIZE = 256
190    
191    @staticmethod
192    def quantize(weight: torch.Tensor) -> dict:
193        """Quantise to Q4_K_M format."""
194        # Reshape to blocks of 256
195        w = weight.reshape(-1, Q4_K_M.BLOCK_SIZE)
196        
197        # Per-block scale (max abs)
198        block_scale = w.abs().amax(dim=-1, keepdim=True).clamp(min=1e-10)
199        
200        # Normalise to [-8, 7] (signed 4-bit)
201        w_norm = (w / block_scale * 7).round().clamp(-8, 7).to(torch.int8)
202        
203        # Per-sub-block (8 weights each) min/max — used for fine-grained correction
204        sub_blocks = w_norm.reshape(w.shape[0], -1, 8).float()
205        sub_mins = sub_blocks.amin(dim=-1)
206        sub_maxs = sub_blocks.amax(dim=-1)
207        
208        return {
209            'codes': w_norm,
210            'block_scales': block_scale.squeeze(-1),
211            'sub_mins': sub_mins,
212            'sub_maxs': sub_maxs,
213        }
214    
215    @staticmethod
216    def dequantize(state: dict) -> torch.Tensor:
217        """Dequantise Q4_K_M back to FP32."""
218        codes = state['codes'].to(torch.float32)
219        block_scales = state['block_scales'].unsqueeze(-1)
220        # Apply block scale
221        w = codes * (block_scales / 7)
222        # Reshape back
223        return w.reshape(-1)

My deeper thought: quantisation IS lossy compression of a manifold
Insight
Quantisation is the same mathematical problem as image compression (JPEG), audio compression (MP3), and vector quantisation (used in VQ-VAE). All are projections from a high-dimensional continuous manifold to a low-dimensional discrete codebook, minimising perceptual/information-theoretic loss. The LLM is a manifold; quantisation is its JPEG.

The mathematical structure of LLM quantisation is identical to JPEG image compression, MP3 audio, and VQ-VAE tokenisers. All four are projections from a continuous manifold to a discrete codebook with a distortion minimisation objective. JPEG uses the Discrete Cosine Transform (DCT) to project 8×8 image patches onto 64 cosine basis functions, then quantises the coefficients — high-frequency components get coarser quantisation because the human eye is less sensitive to them (perceptual weighting). AWQ does the same thing: high-activation channels get finer quantisation because they dominate the output (activation-weighted importance). The "perceptual loss" in JPEG and the "perplexity loss" in AWQ are the same concept — a task-weighted distortion metric.

NF4 is the Lloyd-Max optimal scalar quantiser for N(0,1) weights. The Lloyd-Max algorithm (1982) finds the codebook that minimises MSE for a given source distribution — it places more levels where the PDF is high. For a Gaussian source, the optimal 4-bit codebook is exactly NF4: 16 quantiles of N(0,1). This is the same reason perceptual audio codecs (Opus, AAC) use psychoacoustic masking curves to allocate bits — the codebook adapts to the source distribution. QLoRA's "NF4 is information-theoretically optimal" claim is a Lloyd-Max result, not a heuristic.

This unifies the platform's compression stack: ADR-022 (pgvector) quantises 768-dim float embeddings to int8 + binary quantisation (RaBitQ) for 32× compression — same math, different dimensionality. ADR-023 (QLoRA) quantises 70B model weights to NF4 for 4× compression — same math. ADR-030 (AWQ) does the same with activation-awareness. The DuckDB page stores Parquet with Snappy + Delta encoding — column-wise quantisation of integer timestamps. The Arrow page stores zero-copy columnar buffers — fixed-width quantisation for cache-aligned reads. Everywhere the platform reduces data size, the same Lloyd-Max / rate-distortion theory applies. The unification: the platform is a hierarchy of codebooks, each layer (Bronze raw → Silver conformed → Gold dimensional → semantic layer → embedding → 4-bit weights) is a quantisation step that loses some information but gains efficiency. The Medallion architecture IS a multi-stage quantisation pipeline, with each stage's codebook tuned to its consumer's perceptual metric. The data engineer and the ML engineer are running the same rate-distortion optimisation, just on different manifolds.

Quantization math — the rounding error budget
mathematics
Quantisation is the lossy mapping of FP32 weights to a smaller codebook. The error e = x - dequant(quant(x)) is bounded by half the quantisation step size. Group quantisation reduces error by using per-group scales (each group has its own min/max). The MSE per group is minimised when the codebook is information-theoretically optimal for the weight distribution.

e(x) = x - dequant(quant(x))  ·  MSE = E[‖e‖²] = σ² / 12 (uniform)

Quantisation step Δ = 2·max/2^b where b = bits. Error bounded by Δ/2. Per-group Δ → lower MSE.

Group quantisation

scale_g = max(|w_g|)

Per-group scale → handles long-tail distributions. Group size 64-128 is the sweet spot.

NF4 (NormalFloat)

levels = 16 quantiles of N(0,1)

Information-optimal for normal weights. More levels near 0 (where weights are dense), fewer at the tails.

AWQ (activation-aware)

w' = s · w (top 1% channels)

Scale salient channels before quant → smaller relative error on the channels that matter for the output.

AWQ — why scaling salient channels works
mathematics
The activation-aware insight: not all weight channels matter equally. Channels with larger activation magnitudes contribute more to the layer's output. Scaling them up by (1+s) before quantisation reduces their relative error — the absolute error stays similar (same Δ), but it's now divided by a larger magnitude. AWQ finds the optimal s by grid search over a calibration set.

W' = s · W (salient channels),   e' = e / s  →  relative error ↓

Scaling up salient channels increases their magnitude, so the same absolute quantisation step Δ produces a smaller relative error on the output.

AWQ algorithm (4 steps):

  1. Calibrate: run 128 representative samples through the model, collect per-channel activation statistics (mean abs magnitude).
  2. Identify salient channels: top 1% by activation magnitude (these dominate the output variance).
  3. Grid search s ∈ [0, 1] (20 values): for each, scale salient channels ×(1+s), quantise+dequantise, measure MSE on the calibration set, pick best s.
  4. Apply final scale + standard INT4 group quantisation. Store: 4-bit codes + per-group FP16 scales + per-input-channel FP16 scaling factors.

At inference: scale input by channel_scale → matmul with dequantised weights → divide output by channel_scale. The scaling is transparent to the rest of the model.

10def build_nf4_grid() -> torch.Tensor:
11    """Build the NF4 grid: 16 quantiles of N(0,1) normalised to [-1,1].
12    
13    Information-theoretically optimal 4-bit grid for weights ~ N(0, σ²).
14    Used in QLoRA (ADR-023) for the backward pass.
15    """
16    # 16 quantiles at (i + 0.5) / 16 of N(0,1)
17    p = (torch.arange(16) + 0.5) / 16
18    # Inverse CDF via torch.erfinv: Φ^(-1)(p) = sqrt(2) * erfinv(2p - 1)
19    z = torch.sqrt(torch.tensor(2.0)) * torch.erfinv(2 * p - 1)
20    # Normalise to [-1, 1]
21    return z / z.abs().max()
22 
23NF4_GRID = build_nf4_grid()  # 16 levels in [-1, 1]
24 
25def quantize_nf4(weight: torch.Tensor, group_size: int = 64) -> Tuple[torch.Tensor, torch.Tensor]:
26    """Quantise a weight tensor to NF4.
27    
28    Returns:
29        codes: torch.uint8 (same shape, values 0-15) — 4-bit packed
30        scales: torch.float16 (shape [..., num_groups]) — one scale per group
31    
32    Memory savings: 4 bytes/param → 0.5 bytes/param + small scales = ~6.4× compression.
33    """
34    # Reshape into groups
35    *leading, total = weight.shape
36    num_groups = total // group_size
37    w = weight.reshape(*leading, num_groups, group_size)
38    
39    # Per-group scale = abs_max (since NF4 grid is normalised to [-1,1])
40    scales = w.abs().amax(dim=-1, keepdim=True).clamp(min=1e-10).to(torch.float16)
41    
42    # Normalise to [-1, 1]
43    w_norm = w / scales
44    
45    # Find nearest NF4 level (Euclidean)
46    # w_norm: [..., num_groups, group_size]
47    # NF4_GRID: [16]
48    # Compute distances: [..., num_groups, group_size, 16]
49    dist = (w_norm.unsqueeze(-1) - NF4_GRID.to(w_norm.dtype)).abs()
50    codes = dist.argmin(dim=-1).to(torch.uint8)
51    
52    return codes.reshape(weight.shape), scales.squeeze(-1)
53 
54def dequantize_nf4(codes: torch.Tensor, scales: torch.Tensor, group_size: int = 64) -> torch.Tensor:
55    """Dequantise NF4 codes back to FP16.
56    
57    Used in QLoRA to compute the forward pass: W = dequant_nf4(codes, scales)
58    """
59    *leading, total = codes.shape
60    num_groups = total // group_size
61    c = codes.reshape(*leading, num_groups, group_size)
62    s = scales.unsqueeze(-1).expand(*leading, num_groups, group_size)
63    
64    # Look up NF4 level for each code
65    w_norm = NF4_GRID.to(c.dtype)[c.long()]
66    
67    # Multiply by scale
68    return (w_norm * s).reshape(codes.shape).to(torch.float16)

74class AWQLinear(nn.Module):
75    """AWQ-quantised Linear layer for inference.
76    
77    Stores weights in 4-bit (with per-group scales) but applies activation-aware
78    scaling at dequantisation time. Saves 4× memory with <1% perplexity loss.
79    
80    Args (at construction):
81        in_features, out_features
82        group_size: quantisation group size (default 128)
83        scaling_factor: per-input-channel scale (calibrated offline)
84    
85    Forward:
86        x = scaling_factor * x   # scale UP salient channels
87        w = dequant_4bit(codes, scales)  # INT4 weight reconstruction
88        y = F.linear(x, w)  # standard matmul
89        y = y / scaling_factor  # scale back DOWN
90    """
91    def __init__(self, in_features: int, out_features: int, bias: bool = True,
92                 group_size: int = 128):
93        super().__init__()
94        self.in_features = in_features
95        self.out_features = out_features
96        self.group_size = group_size
97        
98        # 4-bit codes (packed as uint8, 2 codes per byte in production)
99        self.register_buffer(
100            "weight_codes",
101            torch.zeros(out_features, in_features, dtype=torch.uint8),
102        )
103        # Per-group scales (FP16)
104        num_groups = in_features // group_size
105        self.register_buffer(
106            "weight_scales",
107            torch.zeros(out_features, num_groups, dtype=torch.float16),
108        )
109        # Per-input-channel scaling factor (the AWQ trick)
110        self.register_buffer(
111            "channel_scale",
112            torch.ones(in_features, dtype=torch.float16),
113        )
114        if bias:
115            self.register_buffer("bias", torch.zeros(out_features, dtype=torch.float16))
116        else:
117            self.bias = None
118    
119    @torch.no_grad()
120    def quantize(self, weight: torch.Tensor, activation_stats: torch.Tensor,
121                 top_pct: float = 0.01):
122        """Calibrate: find salient channels + scaling factors, then quantise."""
123        # 1. Find salient channels (top 1% by activation magnitude)
124        num_salient = max(1, int(weight.shape[1] * top_pct))
125        _, salient_idx = activation_stats.abs().topk(num_salient)
126        salient_mask = torch.zeros(weight.shape[1], dtype=torch.bool)
127        salient_mask[salient_idx] = True
128        
129        # 2. Grid search for best scaling factor s
130        best_s, best_loss = 0.0, float('inf')
131        for s in torch.linspace(0, 1, 21):
132            # Scale up salient channels, scale down others (balance)
133            scale = torch.ones(weight.shape[1])
134            scale[salient_mask] *= (1 + s)
135            scale[~salient_mask] /= (1 + s * 0.5)
136            
137            # Quantise + dequantise, compute MSE
138            scaled_weight = weight * scale.unsqueeze(0)
139            codes, scales = quantize_nf4(scaled_weight, self.group_size)
140            deq = dequantize_nf4(codes, scales, self.group_size)
141            loss = ((scaled_weight.float() - deq.float()) ** 2).mean()
142            if loss < best_loss:
143                best_loss, best_s = loss, s.item()
144        
145        # 3. Apply best scaling
146        scale = torch.ones(weight.shape[1])
147        scale[salient_mask] *= (1 + best_s)
148        scale[~salient_mask] /= (1 + best_s * 0.5)
149        self.channel_scale = scale.to(torch.float16)
150        
151        # 4. Quantise the scaled weight
152        scaled_weight = weight * scale.unsqueeze(0)
153        codes, scales = quantize_nf4(scaled_weight, self.group_size)
154        self.weight_codes = codes
155        self.weight_scales = scales
156    
157    def forward(self, x: torch.Tensor) -> torch.Tensor:
158        # 1. Apply channel scaling (scale up salient inputs)
159        x = x.float() * self.channel_scale.float()
160        
161        # 2. Reconstruct weights in 4-bit, upcast to compute dtype
162        w = dequantize_nf4(self.weight_codes, self.weight_scales, self.group_size)
163        w = w.to(x.dtype)
164        
165        # 3. Standard matmul
166        out = torch.functional.F.linear(x, w)
167        
168        # 4. Scale back down (undo the channel scaling)
169        out = out / self.channel_scale.float()
170        
171        if self.bias is not None:
172            out = out + self.bias.float()
173        return out.to(x.dtype)

179class Q4_K_M:
180    """llama.cpp Q4_K_M super-block quantisation.
181    
182    Layout (per super-block of 256 weights):
183        - 1 × 4-bit scale (FP16): overall block scale
184        - 2 × 6-bit scales (FP16, computed as min/max): per-sub-block scale  
185        - 256 × 4-bit codes: one per weight
186    
187    Effective bits/weight: 4 + (16 + 32) / 256 = 4.19 bits/weight
188    """
189    BLOCK_SIZE = 256
190    
191    @staticmethod
192    def quantize(weight: torch.Tensor) -> dict:
193        """Quantise to Q4_K_M format."""
194        # Reshape to blocks of 256
195        w = weight.reshape(-1, Q4_K_M.BLOCK_SIZE)
196        
197        # Per-block scale (max abs)
198        block_scale = w.abs().amax(dim=-1, keepdim=True).clamp(min=1e-10)
199        
200        # Normalise to [-8, 7] (signed 4-bit)
201        w_norm = (w / block_scale * 7).round().clamp(-8, 7).to(torch.int8)
202        
203        # Per-sub-block (8 weights each) min/max — used for fine-grained correction
204        sub_blocks = w_norm.reshape(w.shape[0], -1, 8).float()
205        sub_mins = sub_blocks.amin(dim=-1)
206        sub_maxs = sub_blocks.amax(dim=-1)
207        
208        return {
209            'codes': w_norm,
210            'block_scales': block_scale.squeeze(-1),
211            'sub_mins': sub_mins,
212            'sub_maxs': sub_maxs,
213        }
214    
215    @staticmethod
216    def dequantize(state: dict) -> torch.Tensor:
217        """Dequantise Q4_K_M back to FP32."""
218        codes = state['codes'].to(torch.float32)
219        block_scales = state['block_scales'].unsqueeze(-1)
220        # Apply block scale
221        w = codes * (block_scales / 7)
222        # Reshape back
223        return w.reshape(-1)

My deeper thought: quantisation IS lossy compression of a manifold
Insight
Quantisation is the same mathematical problem as image compression (JPEG), audio compression (MP3), and vector quantisation (used in VQ-VAE). All are projections from a high-dimensional continuous manifold to a low-dimensional discrete codebook, minimising perceptual/information-theoretic loss. The LLM is a manifold; quantisation is its JPEG.

The mathematical structure of LLM quantisation is identical to JPEG image compression, MP3 audio, and VQ-VAE tokenisers. All four are projections from a continuous manifold to a discrete codebook with a distortion minimisation objective. JPEG uses the Discrete Cosine Transform (DCT) to project 8×8 image patches onto 64 cosine basis functions, then quantises the coefficients — high-frequency components get coarser quantisation because the human eye is less sensitive to them (perceptual weighting). AWQ does the same thing: high-activation channels get finer quantisation because they dominate the output (activation-weighted importance). The "perceptual loss" in JPEG and the "perplexity loss" in AWQ are the same concept — a task-weighted distortion metric.

NF4 is the Lloyd-Max optimal scalar quantiser for N(0,1) weights. The Lloyd-Max algorithm (1982) finds the codebook that minimises MSE for a given source distribution — it places more levels where the PDF is high. For a Gaussian source, the optimal 4-bit codebook is exactly NF4: 16 quantiles of N(0,1). This is the same reason perceptual audio codecs (Opus, AAC) use psychoacoustic masking curves to allocate bits — the codebook adapts to the source distribution. QLoRA's "NF4 is information-theoretically optimal" claim is a Lloyd-Max result, not a heuristic.

This unifies the platform's compression stack: ADR-022 (pgvector) quantises 768-dim float embeddings to int8 + binary quantisation (RaBitQ) for 32× compression — same math, different dimensionality. ADR-023 (QLoRA) quantises 70B model weights to NF4 for 4× compression — same math. ADR-030 (AWQ) does the same with activation-awareness. The DuckDB page stores Parquet with Snappy + Delta encoding — column-wise quantisation of integer timestamps. The Arrow page stores zero-copy columnar buffers — fixed-width quantisation for cache-aligned reads. Everywhere the platform reduces data size, the same Lloyd-Max / rate-distortion theory applies. The unification: the platform is a hierarchy of codebooks, each layer (Bronze raw → Silver conformed → Gold dimensional → semantic layer → embedding → 4-bit weights) is a quantisation step that loses some information but gains efficiency. The Medallion architecture IS a multi-stage quantisation pipeline, with each stage's codebook tuned to its consumer's perceptual metric. The data engineer and the ML engineer are running the same rate-distortion optimisation, just on different manifolds.
