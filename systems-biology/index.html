FBA math — Linear Programming on the stoichiometric matrix
mathematics
FBA reformulates metabolism as an LP. The stoichiometric matrix S captures the topology (m metabolites × n reactions, entries = net stoichiometric coefficient). Mass balance S·v=0 enforces steady state (no accumulation). Objective c·v maximises biomass (the biomass reaction has coefficient 1, all others 0). Solved by Simplex or Interior-Point method.

max c · v   s.t.   S · v = 0,   vmin ≤ v ≤ vmax

S = (m × n) stoichiometric matrix, v = (n,) flux vector, c = (n,) objective coefficients (biomass=1).

Stoichiometric matrix S

S[i,j] = ±coefficient of metabolite i in reaction j

Sparse — typically <5 non-zeros per column. For Recon 3D: 8400×13500 = 113M entries, ~70K non-zeros.

Mass balance S·v = 0

d[metabolite]/dt = 0 (steady state)

Each metabolite's production rate = consumption rate. Reasonable over long timescales (> seconds).

Biomass objective

c · v → biomass reaction flux

Biomass reaction consumes ~50 precursors in cell-composition ratios. Maximise it = max growth rate.

Modern papers — Recon 3D, STRING, MOFA+, Karr whole-cell
The four reference systems for modern systems biology: (1) Recon 3D (Brunk 2018, Nature — human metabolic network with 13.5K reactions). (2) STRING database (Szklarczyk 2023, Nucleic Acids Research — 19.5M PPIs). (3) MOFA+ (Argelaguet 2020, Genome Biology — Bayesian multi-omics factor analysis). (4) Karr 2012 (Cell — first whole-cell simulation, M. genitalium 525 genes).

Recon 3D (Brunk et al. 2018, Nature Biotechnology 36): The human metabolic network — 13,500 reactions, 8,400 metabolites, 3,200 genes (GPR associations), 3D spatial compartments. The reference for any FBA on human cells. Genetic diseases (inborn errors of metabolism) map to Recon 3D genes — the model predicts disease phenotype from genotype. Modern: Recon 3D + AlphaFold protein structures → mechanistic genotype-phenotype link.

STRING database (Szklarczyk et al. 2023, Nucleic Acids Research): 19.5M PPIs across 19,000 organisms, scored by confidence (0-1) from 7 evidence channels (genomic context, gene co-expression, high-throughput experiments, text mining, etc.). Used for: function prediction (guilt-by-association), essentiality prediction (hub proteins), pathway reconstruction. Modern: STRING + Graph Neural Networks (PPINetwork in low-level code) for function prediction.

MOFA+ (Argelaguet et al. 2020, Genome Biology): Bayesian factor analysis that decomposes multi-omics matrices into shared + modality-specific latent factors. Discovers biological axes of variation (cell cycle, metabolic state, tissue identity, stress response) that are interpretable. Production: MOFA2 R/Python package, scales to 10 omics × 10K samples. The mathematical structure is the same as PCA — just applied jointly across matrices.

Karr 2012 whole-cell (Cell 150): First complete simulation of a single cell (Mycoplasma genitalium, 525 genes, 28 chromosomes). Integrated 28 cellular processes (metabolism, transcription, translation, DNA replication, cell division) into a single 9-hour simulation. Took 10 hours of CPU. Required careful sub-model integration — each process has its own time scale and solver. North star for systems biology: a full human whole-cell simulation (20K genes × 13.5K reactions × 28 processes) is the moonshot.

12class FBASolver:
13    """Flux Balance Analysis via linear programming.
14    
15    max  c · v
16    s.t. S · v = 0     (steady-state mass balance)
17         v_min ≤ v ≤ v_max
18    
19    S = stoichiometric matrix (m metabolites × n reactions)
20    
21    Production: COBRApy with GLPK (free) or Gurobi (commercial, 1000x faster).
22    """
23    def __init__(self, S: torch.Tensor, c: torch.Tensor,
24                 v_min: torch.Tensor, v_max: torch.Tensor):
25        """
26        Args:
27            S: (m, n) stoichiometric matrix
28            c: (n,) objective coefficients (1 for biomass, 0 else)
29            v_min, v_max: (n,) capacity bounds
30        """
31        self.S = S
32        self.c = c
33        self.v_min = v_min
34        self.v_max = v_max
35    
36    def solve(self, max_iter: int = 1000) -> Tuple[torch.Tensor, float]:
37        """Solve FBA via projected gradient ascent (simplified).
38        
39        Production uses LP solver (Simplex/Interior-point).
40        For demo: project gradient onto feasible region.
41        """
42        n = self.c.shape[0]
43        v = (self.v_min + self.v_max) / 2  # start in middle of bounds
44        v.requires_grad_(True)
45        
46        opt = torch.optim.Adam([v], lr=0.01)
47        
48        for _ in range(max_iter):
49            opt.zero_grad()
50            # Objective: maximise c · v (minimise -c · v)
51            obj = -torch.dot(self.c, v)
52            # Mass balance constraint: ||S · v||² should be 0
53            mass_balance_violation = (self.S @ v).pow(2).sum()
54            # Bounds: penalise outside [v_min, v_max]
55            lower_violation = F.relu(self.v_min - v).pow(2).sum()
56            upper_violation = F.relu(v - self.v_max).pow(2).sum()
57            
58            loss = obj + 100 * mass_balance_violation + 100 * (lower_violation + upper_violation)
59            loss.backward()
60            opt.step()
61        
62        return v.detach(), torch.dot(self.c, v.detach()).item()
63    
64    def gene_essentiality(self, gene_knockouts: List[int]) -> Dict[int, float]:
65        """For each gene knockout, compute biomass.
66        
67        Knockout = set v_max[gene] = 0 (no flux through that reaction).
68        """
69        results = {}
70        for gene_idx in gene_knockouts:
71            v_max_ko = self.v_max.clone()
72            v_max_ko[gene_idx] = 0
73            solver = FBASolver(self.S, self.c, self.v_min, v_max_ko)
74            _, biomass = solver.solve(max_iter=200)
75            results[gene_idx] = biomass
76        return results

82class PPINetwork(nn.Module):
83    """Protein-Protein Interaction network analysis via GNN.
84    
85    Production: PyTorch Geometric (PyG) with SAGEConv/GATConv layers.
86    Here: simplified message-passing GNN.
87    
88    Tasks:
89        - Function prediction (multi-label classification)
90        - Essentiality prediction (binary: is protein essential?)
91        - Pathway assignment (multi-class)
92    
93    Data: STRING PPI network (19.5M interactions across 19K organisms).
94    """
95    def __init__(self, num_proteins: int, hidden_dim: int = 64,
96                 num_classes: int = 100, num_layers: int = 3):
97        super().__init__()
98        self.protein_embed = nn.Embedding(num_proteins, hidden_dim)
99        # Message passing layers
100        self.layers = nn.ModuleList([
101            nn.Linear(hidden_dim, hidden_dim) for _ in range(num_layers)
102        ])
103        # Output: function prediction (multi-label)
104        self.head = nn.Linear(hidden_dim, num_classes)
105        self.dropout = nn.Dropout(0.2)
106    
107    def forward(self, node_ids: torch.Tensor,
108                edge_index: torch.Tensor) -> torch.Tensor:
109        """Forward pass.
110        
111        Args:
112            node_ids: (N,) protein indices
113            edge_index: (2, E) PPI edges (src, dst)
114        
115        Returns: (N, num_classes) function prediction logits
116        """
117        h = self.protein_embed(node_ids)
118        
119        # Message passing: aggregate neighbours
120        for layer in self.layers:
121            # Self update
122            h_self = layer(h)
123            # Aggregate neighbours (mean aggregation)
124            src, dst = edge_index
125            msg = h[src]  # (E, hidden)
126            agg = torch.zeros_like(h)
127            agg.index_add_(0, dst, msg)  # sum messages per dst
128            counts = torch.zeros(h.shape[0], device=h.device)
129            counts.index_add_(0, dst, torch.ones_like(dst, dtype=h.dtype))
130            counts = counts.clamp(min=1)
131            h_neighbours = agg / counts.unsqueeze(-1)
132            
133            h = F.relu(h_self + h_neighbours)
134            h = self.dropout(h)
135        
136        return self.head(h)  # (N, num_classes)

138def pagerank(adj: Dict[int, Dict[int, float]],
139             d: float = 0.85, iters: int = 100) -> Dict[int, float]:
140    """PageRank on PPI network.
141    
142    PR(n) = (1-d)/N + d·Σ PR(m)/outdeg(m) for m→n
143    
144    Identifies hub proteins (high PageRank = essential).
145    """
146    nodes = list(adj.keys())
147    n = len(nodes)
148    pr = {node: 1/n for node in nodes}
149    
150    for _ in range(iters):
151        new_pr = {node: (1-d)/n for node in nodes}
152        for node in nodes:
153            for nbr, weight in adj[node].items():
154                out_w = sum(adj[node].values())
155                if out_w > 0:
156                    new_pr[nbr] += d * pr[node] * weight / out_w
157        pr = new_pr
158    
159    return pr

177            dims_per_modality: [D_1, D_2, ...] feature counts per omics

179        """

181        self.k = k

188        self.factor_scale = nn.Parameter(torch.ones(k))

192        """Reconstruct each omics matrix from latent factors.
193        
194        Args:
195            z: (B, K) latent factor matrix
196        
197        Returns: list of (B, D_m) reconstructed omics
198        """
199        return [w(z) for w in self.weights]

203        
204        Production: stochastic variational inference (Bayesian).
205        """
206        n_samples = X_list[0].shape[0]
207        # Initialise latent factors
208        Z = torch.randn(n_samples, self.k, requires_grad=True)

210            {'params': self.parameters(), 'lr': 0.01},
211            {'params': [Z], 'lr': 0.01},
212        ])
213

216            X_recon_list = self.forward(Z)

234    """Karr 2012 whole-cell simulation pattern.
235    
236    Integrates ALL cellular processes into one simulation:
237        - Metabolism (FBA, sub-second timestep)
238        - RNA synthesis (transcription, ~1 min per gene)
239        - Protein synthesis (translation, ~2 min per protein)
240        - DNA replication (cell cycle dependent)
241        - Cell growth (volume expansion)
242    
243    Production: Karr 2012 simulated M. genitalium (525 genes) in 10h for 9h cell cycle.
244    """
245    def __init__(self, n_genes: int, n_metabolites: int, n_reactions: int):
246        self.n_genes = n_genes
247        self.n_metabolites = n_metabolites
248        self.n_reactions = n_reactions
249        # State at time t
250        self.mrna = torch.zeros(n_genes)  # mRNA counts
251        self.protein = torch.zeros(n_genes)  # protein counts
252        self.metabolite = torch.zeros(n_metabolites)  # metabolite concentrations
253        self.dna_replicated = False
254        self.cell_volume = 1.0  # fL
255        self.time = 0.0
256    
257    def step(self, dt: float = 1.0):
258        """One simulation step (1 second default).
259        
260        Updates: mRNA decay, translation, metabolism (FBA), DNA replication.
261        """
262        # 1. mRNA decay (half-life ~5 min)
263        decay_rate = math.log(2) / (5 * 60)
264        self.mrna *= math.exp(-decay_rate * dt)
265        
266        # 2. Transcription (random genes fire)
267        # Poisson process: rate = promoter strength * dt
268        # (simplified — production uses kinetic model)
269        for gene_idx in torch.randint(0, self.n_genes, (5,)):
270            self.mrna[gene_idx] += 1
271        
272        # 3. Translation (mRNA → protein)
273        # Each mRNA produces 10 protein/min
274        for gene_idx in range(self.n_genes):
275            if self.mrna[gene_idx] > 0:
276                produced = self.mrna[gene_idx] * (10 / 60) * dt
277                self.protein[gene_idx] += produced
278        
279        # 4. Protein decay (half-life ~10 hours)
280        protein_decay = math.log(2) / (10 * 3600)
281        self.protein *= math.exp(-protein_decay * dt)
282        
283        # 5. DNA replication (when cell volume doubles)
284        if self.cell_volume >= 2.0 and not self.dna_replicated:
285            self.dna_replicated = True
286        
287        # 6. Cell division
288        if self.cell_volume >= 2.0 and self.dna_replicated:
289            self.cell_volume = 1.0
290            self.dna_replicated = False
291            self.mrna /= 2
292            self.protein /= 2
293        
294        self.time += dt
295    
296    def simulate(self, total_time: float = 9 * 3600, dt: float = 1.0):
297        """Simulate one cell cycle (9 hours for M. genitalium)."""
298        n_steps = int(total_time / dt)
299        history = []
300        for _ in range(n_steps):
301            self.step(dt)
302            if _ % 1000 == 0:
303                history.append({
304                    'time': self.time,
305                    'cell_volume': self.cell_volume,
306                    'total_mrna': self.mrna.sum().item(),
307                    'total_protein': self.protein.sum().item(),
308                })
309        return history

FBA math — Linear Programming on the stoichiometric matrix
mathematics
FBA reformulates metabolism as an LP. The stoichiometric matrix S captures the topology (m metabolites × n reactions, entries = net stoichiometric coefficient). Mass balance S·v=0 enforces steady state (no accumulation). Objective c·v maximises biomass (the biomass reaction has coefficient 1, all others 0). Solved by Simplex or Interior-Point method.

max c · v   s.t.   S · v = 0,   vmin ≤ v ≤ vmax

S = (m × n) stoichiometric matrix, v = (n,) flux vector, c = (n,) objective coefficients (biomass=1).

Stoichiometric matrix S

S[i,j] = ±coefficient of metabolite i in reaction j

Sparse — typically <5 non-zeros per column. For Recon 3D: 8400×13500 = 113M entries, ~70K non-zeros.

Mass balance S·v = 0

d[metabolite]/dt = 0 (steady state)

Each metabolite's production rate = consumption rate. Reasonable over long timescales (> seconds).

Biomass objective

c · v → biomass reaction flux

Biomass reaction consumes ~50 precursors in cell-composition ratios. Maximise it = max growth rate.

12class FBASolver:
13    """Flux Balance Analysis via linear programming.
14    
15    max  c · v
16    s.t. S · v = 0     (steady-state mass balance)
17         v_min ≤ v ≤ v_max
18    
19    S = stoichiometric matrix (m metabolites × n reactions)
20    
21    Production: COBRApy with GLPK (free) or Gurobi (commercial, 1000x faster).
22    """
23    def __init__(self, S: torch.Tensor, c: torch.Tensor,
24                 v_min: torch.Tensor, v_max: torch.Tensor):
25        """
26        Args:
27            S: (m, n) stoichiometric matrix
28            c: (n,) objective coefficients (1 for biomass, 0 else)
29            v_min, v_max: (n,) capacity bounds
30        """
31        self.S = S
32        self.c = c
33        self.v_min = v_min
34        self.v_max = v_max
35    
36    def solve(self, max_iter: int = 1000) -> Tuple[torch.Tensor, float]:
37        """Solve FBA via projected gradient ascent (simplified).
38        
39        Production uses LP solver (Simplex/Interior-point).
40        For demo: project gradient onto feasible region.
41        """
42        n = self.c.shape[0]
43        v = (self.v_min + self.v_max) / 2  # start in middle of bounds
44        v.requires_grad_(True)
45        
46        opt = torch.optim.Adam([v], lr=0.01)
47        
48        for _ in range(max_iter):
49            opt.zero_grad()
50            # Objective: maximise c · v (minimise -c · v)
51            obj = -torch.dot(self.c, v)
52            # Mass balance constraint: ||S · v||² should be 0
53            mass_balance_violation = (self.S @ v).pow(2).sum()
54            # Bounds: penalise outside [v_min, v_max]
55            lower_violation = F.relu(self.v_min - v).pow(2).sum()
56            upper_violation = F.relu(v - self.v_max).pow(2).sum()
57            
58            loss = obj + 100 * mass_balance_violation + 100 * (lower_violation + upper_violation)
59            loss.backward()
60            opt.step()
61        
62        return v.detach(), torch.dot(self.c, v.detach()).item()
63    
64    def gene_essentiality(self, gene_knockouts: List[int]) -> Dict[int, float]:
65        """For each gene knockout, compute biomass.
66        
67        Knockout = set v_max[gene] = 0 (no flux through that reaction).
68        """
69        results = {}
70        for gene_idx in gene_knockouts:
71            v_max_ko = self.v_max.clone()
72            v_max_ko[gene_idx] = 0
73            solver = FBASolver(self.S, self.c, self.v_min, v_max_ko)
74            _, biomass = solver.solve(max_iter=200)
75            results[gene_idx] = biomass
76        return results

82class PPINetwork(nn.Module):
83    """Protein-Protein Interaction network analysis via GNN.
84    
85    Production: PyTorch Geometric (PyG) with SAGEConv/GATConv layers.
86    Here: simplified message-passing GNN.
87    
88    Tasks:
89        - Function prediction (multi-label classification)
90        - Essentiality prediction (binary: is protein essential?)
91        - Pathway assignment (multi-class)
92    
93    Data: STRING PPI network (19.5M interactions across 19K organisms).
94    """
95    def __init__(self, num_proteins: int, hidden_dim: int = 64,
96                 num_classes: int = 100, num_layers: int = 3):
97        super().__init__()
98        self.protein_embed = nn.Embedding(num_proteins, hidden_dim)
99        # Message passing layers
100        self.layers = nn.ModuleList([
101            nn.Linear(hidden_dim, hidden_dim) for _ in range(num_layers)
102        ])
103        # Output: function prediction (multi-label)
104        self.head = nn.Linear(hidden_dim, num_classes)
105        self.dropout = nn.Dropout(0.2)
106    
107    def forward(self, node_ids: torch.Tensor,
108                edge_index: torch.Tensor) -> torch.Tensor:
109        """Forward pass.
110        
111        Args:
112            node_ids: (N,) protein indices
113            edge_index: (2, E) PPI edges (src, dst)
114        
115        Returns: (N, num_classes) function prediction logits
116        """
117        h = self.protein_embed(node_ids)
118        
119        # Message passing: aggregate neighbours
120        for layer in self.layers:
121            # Self update
122            h_self = layer(h)
123            # Aggregate neighbours (mean aggregation)
124            src, dst = edge_index
125            msg = h[src]  # (E, hidden)
126            agg = torch.zeros_like(h)
127            agg.index_add_(0, dst, msg)  # sum messages per dst
128            counts = torch.zeros(h.shape[0], device=h.device)
129            counts.index_add_(0, dst, torch.ones_like(dst, dtype=h.dtype))
130            counts = counts.clamp(min=1)
131            h_neighbours = agg / counts.unsqueeze(-1)
132            
133            h = F.relu(h_self + h_neighbours)
134            h = self.dropout(h)
135        
136        return self.head(h)  # (N, num_classes)

138def pagerank(adj: Dict[int, Dict[int, float]],
139             d: float = 0.85, iters: int = 100) -> Dict[int, float]:
140    """PageRank on PPI network.
141    
142    PR(n) = (1-d)/N + d·Σ PR(m)/outdeg(m) for m→n
143    
144    Identifies hub proteins (high PageRank = essential).
145    """
146    nodes = list(adj.keys())
147    n = len(nodes)
148    pr = {node: 1/n for node in nodes}
149    
150    for _ in range(iters):
151        new_pr = {node: (1-d)/n for node in nodes}
152        for node in nodes:
153            for nbr, weight in adj[node].items():
154                out_w = sum(adj[node].values())
155                if out_w > 0:
156                    new_pr[nbr] += d * pr[node] * weight / out_w
157        pr = new_pr
158    
159    return pr

165class MultiOmicsFactorAnalysis(nn.Module):
166    """MOFA+ (Argelaguet 2020) — Bayesian multi-omics factor analysis.
167    
168    Decomposes: X_m = W_m · Z + ε_m, for each omics modality m
169    
170    Z = shared latent factors (across all omics, shape: K × N)
171    W_m = modality-specific weights (shape: D_m × K)
172    
173    Production: MOFA2 R/Python package, full Bayesian (variational inference).
174    """
175    def __init__(self, dims_per_modality: List[int], k: int = 10):
176        """Args:
177            dims_per_modality: [D_1, D_2, ...] feature counts per omics
178            k: number of latent factors (typically 10-50)
179        """
180        super().__init__()
181        self.k = k
182        # Modality-specific weights
183        self.weights = nn.ModuleList([
184            nn.Linear(k, d, bias=False) for d in dims_per_modality
185        ])
186        # Latent factors (will be optimised per dataset)
187        # In production: Bayesian variational inference with priors
188        self.factor_scale = nn.Parameter(torch.ones(k))
189        self.factor_bias = nn.Parameter(torch.zeros(k))
190    
191    def forward(self, z: torch.Tensor) -> List[torch.Tensor]:
192        """Reconstruct each omics matrix from latent factors.
193        
194        Args:
195            z: (B, K) latent factor matrix
196        
197        Returns: list of (B, D_m) reconstructed omics
198        """
199        return [w(z) for w in self.weights]
200    
201    def fit(self, X_list: List[torch.Tensor], max_iter: int = 500):
202        """Fit via alternating optimisation (simplified).
203        
204        Production: stochastic variational inference (Bayesian).
205        """
206        n_samples = X_list[0].shape[0]
207        # Initialise latent factors
208        Z = torch.randn(n_samples, self.k, requires_grad=True)
209        opt = torch.optim.Adam([
210            {'params': self.parameters(), 'lr': 0.01},
211            {'params': [Z], 'lr': 0.01},
212        ])
213        
214        for _ in range(max_iter):
215            opt.zero_grad()
216            X_recon_list = self.forward(Z)
217            # Reconstruction loss per modality
218            loss = 0
219            for X, X_recon in zip(X_list, X_recon_list):
220                loss += F.mse_loss(X_recon, X)
221            # Regularisation: sparsity on W (encourages interpretable factors)
222            for w in self.weights:
223                loss += 0.01 * w.weight.abs().mean()
224            loss.backward()
225            opt.step()
226        
227        return Z.detach()

233class WholeCellModel:
234    """Karr 2012 whole-cell simulation pattern.
235    
236    Integrates ALL cellular processes into one simulation:
237        - Metabolism (FBA, sub-second timestep)
238        - RNA synthesis (transcription, ~1 min per gene)
239        - Protein synthesis (translation, ~2 min per protein)
240        - DNA replication (cell cycle dependent)
241        - Cell growth (volume expansion)
242    
243    Production: Karr 2012 simulated M. genitalium (525 genes) in 10h for 9h cell cycle.
244    """
245    def __init__(self, n_genes: int, n_metabolites: int, n_reactions: int):
246        self.n_genes = n_genes
247        self.n_metabolites = n_metabolites
248        self.n_reactions = n_reactions
249        # State at time t
250        self.mrna = torch.zeros(n_genes)  # mRNA counts
251        self.protein = torch.zeros(n_genes)  # protein counts
252        self.metabolite = torch.zeros(n_metabolites)  # metabolite concentrations
253        self.dna_replicated = False
254        self.cell_volume = 1.0  # fL
255        self.time = 0.0
256    
257    def step(self, dt: float = 1.0):
258        """One simulation step (1 second default).
259        
260        Updates: mRNA decay, translation, metabolism (FBA), DNA replication.
261        """
262        # 1. mRNA decay (half-life ~5 min)
263        decay_rate = math.log(2) / (5 * 60)
264        self.mrna *= math.exp(-decay_rate * dt)
265        
266        # 2. Transcription (random genes fire)
267        # Poisson process: rate = promoter strength * dt
268        # (simplified — production uses kinetic model)
269        for gene_idx in torch.randint(0, self.n_genes, (5,)):
270            self.mrna[gene_idx] += 1
271        
272        # 3. Translation (mRNA → protein)
273        # Each mRNA produces 10 protein/min
274        for gene_idx in range(self.n_genes):
275            if self.mrna[gene_idx] > 0:
276                produced = self.mrna[gene_idx] * (10 / 60) * dt
277                self.protein[gene_idx] += produced
278        
279        # 4. Protein decay (half-life ~10 hours)
280        protein_decay = math.log(2) / (10 * 3600)
281        self.protein *= math.exp(-protein_decay * dt)
282        
283        # 5. DNA replication (when cell volume doubles)
284        if self.cell_volume >= 2.0 and not self.dna_replicated:
285            self.dna_replicated = True
286        
287        # 6. Cell division
288        if self.cell_volume >= 2.0 and self.dna_replicated:
289            self.cell_volume = 1.0
290            self.dna_replicated = False
291            self.mrna /= 2
292            self.protein /= 2
293        
294        self.time += dt
295    
296    def simulate(self, total_time: float = 9 * 3600, dt: float = 1.0):
297        """Simulate one cell cycle (9 hours for M. genitalium)."""
298        n_steps = int(total_time / dt)
299        history = []
300        for _ in range(n_steps):
301            self.step(dt)
302            if _ % 1000 == 0:
303                history.append({
304                    'time': self.time,
305                    'cell_volume': self.cell_volume,
306                    'total_mrna': self.mrna.sum().item(),
307                    'total_protein': self.protein.sum().item(),
308                })
309        return history
